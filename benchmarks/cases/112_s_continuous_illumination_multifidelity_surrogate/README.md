# Case112: Task002 S-only continuous-illumination multi-fidelity surrogate

Case112 is the hash-bound authority for Task002.  M1 freezes the S-only input
schema, exact-zero/out-of-domain behavior, angle designs, analytic order-window
audit, canonical dataset layout, split immutability, campaign resume rules, and
all later surrogate acceptance thresholds before any validation result is seen.

The numerical core remains the qualified Hybrid p4/p6 h10 M120 MPI2 route.  The
Task002 campaign wrapper narrows it to S polarization and records a separate
Task002 execution identity.  It does not change ordinary solver defaults and does
not develop Hybrid-P.

`records/m1_scaffold.json` is generated deterministically from code.  Raw PDE
artifacts, later compact datasets, and model packages are not stored here unless
they are lightweight and hash-bound.  Four-dimensional bulk generation remains
forbidden until the M2 center-anchor and angle-pilot gate passes.
