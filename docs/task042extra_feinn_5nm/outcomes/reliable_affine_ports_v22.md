# V22：可靠仿射总场与解析面端口组件

已实现双分量总场输出和解析面端口，给定存储D/H下的准确算术、面块/作用及空气资格通过；实际原点投影对独立物理积分仍失败，严格角色资格未闭合。两份保存相位场在新算子中超残差门，启动链各执行一次同G0/p/κ修正，保留为研究数据。独立比较结论为 **STRICT_FINITE_P_FIELD_MODE_FAIL / REFERENCE_LIMITED**。没有NN训练或有效NN净增益，也没有合格O6参考或原尺寸解。

## 为什么改输出和面投影

总场由散射场加背景构成。相加时丢掉的几个最低位，对体场通常很小，却会被某些衰减很快的端口模式放大。因此，新格式把相加主值和舍入余量分别存为两个complex128数组；两者一起定义完整FE向量。旧单数组、原散射系数和旧失败都不改。代价是多存一个全FE向量，并要求每个线性消费者分别作用于两部分。

实现先分别展开MPC、计算体作用、原点端口和物理E/curl/H，再在物理输出层以guard digits组合；不会先合回一个double FE向量。完整内部系数、六点复样本和四类全模式也使用同一数学总场。原点回代用binary64乘积的整数准确累积及有理H除法，独立checker用Fraction精确和与110位Decimal乘加；二者不共用回代实现。最终功率转为float，部分出射通道在物理输出完成后转为complex128，这是明确的终端输出舍入，不能称所有物理量算术精确。原1e-10恢复门不变。

面端口投影需要积分多项式基函数与振荡复指数的乘积。旧q15对稳定的体积分足够，并不能自动证明对真实340通道的面相位跨度也足够。新显式opt-in组件先把仿射平面上的Nédélec切向迹分解为两方向Legendre多项式，再用解析Fourier矩。原几何、材料、物理k、极化、上下法向、共轭、参考平面、Piola和orientation均保留。这里只改变端口积分算法，形成一个明确的新离散算子版本；不是提高FE阶次，也不是近轴/标量近似。

```math
\int_{-1}^{1}P_\ell(t)e^{izt}\,dt=2i^\ell j_\ell(z),\qquad
z=\tfrac12(k_{\mathrm{mode},t}-\kappa_t)h_t.
```

算法使用稳定的小参数级数/球Bessel求值，负频按奇偶性处理，不在零点作不稳定向上递推。多项式变换使用p+1点Gauss，只积分有限阶多项式；振荡部分不由该求积近似。独立oracle直接在物理面评价Basix基函数，采用在观察结果前由最大相位跨度与p固定的两档规则，既不调用producer的Bessel函数，也不共用多项式变换。

端口支持由拓扑面闭包构造，保留所有真实边/面小项，禁止按幅值删项。普通kappa=0及固定横向相位均受检；非仿射/非水平面、复杂切向波数或不可逆的法向相位明确拒绝此入口，ordinary默认不变。p6本次只完成小面组件资格，没有恢复GX560 O6参考。

## 最小接入合同

接收方为主线既有`_ReusableSurfaceComponentAssembler`/carrier。`face_polynomial(model,cell,facet)`返回物理、定向后的局部多项式；`AffineFacePolynomial.blocks(modes,kappa,side)`返回closure_dof×mode的B及mode×closure_dof的D。`original_normalization`返回按完整周期面积定义的正实对角H，不能把单个面面积当全局H，也不能把每面H相加。接收方对B作共轭约束映射、对D作原约束映射各一次；不重复Floquet相位。

输出组件`affine_state`保存散射、背景、total_hi/lo及alpha_total_hi/lo；`SplitVector.map(action)`强制分别作用，隐式ndarray转换拒绝。模式key、两极化、side、参考面、材料/波数、source及ABI逐项绑定。相关src、tests、checker按六类依赖组交付；没有production default或merge授权。

原尺寸32060-key完整oracle需要已冻结manifest的原字节。指定本体缺失时，只交函数签名、布局、物理前提、已有340模式证据与准确缺项；不制造模式库存，不复制主线W1全部对象，不构造32060平方稠密H、不复制dot后端/存储。没有相同局部输入和输出、同精度的冷准备到checker完整基线，就不报告20%倍率。局部组件资格或缓存节省均不能当全局2TB/48小时证书，更不是NN增益。

## 归因口径

三份冻结场的c保持原字节，比较旧q15块到新解析块的作用、背景/入射RHS变化、新原方程残差与准确alpha变化；逐模式保存原值、实际分母、绝对和相对差。原数组交叉项保留，避免把两个大变化相消后的结果误当零影响。舍入问题以hi/lo的原点恢复独立判定；端口积分问题以可靠新算子判定；E3/E4体空间差异仍用原共同积分/区域及严格有限p门，不能由功率接近代替。

新算子未改变c时，旧全场与区域积分按原hash复用，不重复40分钟积分来重证同一向量。只在可靠新算子使某保存E3/E4的native残差>1e-6、且共享/角色/全部输出消费前置均通过时，才准入一次同G0/同p/同kappa的修正求解。新解须完整未凝聚、独立弱式和原点/MPC门通过，释放全局factor/CSR并证明RSS下降后才完整后处理。没有合格严格参考仍为REFERENCE_LIMITED。

上述是Review的准入要求。实际启动链用已通过的给定D/H算术、块/作用及空气标记；最终独立保存向量checker发现原点物理投影仍超1e-10，说明块配对不能替代敏感实际向量配对，不能追认严格角色资格。两次修正保留为研究数据及真实成本，所有未过项另表列出；最小接入包只交可选组件，不授予生产资格。
