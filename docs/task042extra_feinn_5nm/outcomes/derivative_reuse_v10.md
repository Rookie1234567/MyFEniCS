# V10 完整参数导数复用与真实成本

本轮在同一个网络参数处保存隐藏激活和 tanh 导数的 FP64 数值，减少多次参数方向导数的重复计算。代价是约1.10 GiB常驻缓存、建立和释放时间；网络、完整有限元插值、原方程及GN目标均不变。缓存不是预条件器，不代表曲率条件数改善。

JVP回答“参数沿这个方向变化时，完整FE系数如何变化”，不是空间导数。VJP把完整复FE dual准确传回实网络参数；GN用这些作用描述残差的一阶变化，加mu控制步长，并以真实非线性目标判断是否接受。K是GN曲率，未宣称为完整非线性Hessian。

静态身份包括矩、owner、orientation、Piola、坐标几何、固定相位、dtype；动态身份包括全部参数与buffers字节hash/版本。同theta改变mu可以复用，试探不污染基点，接受立即失效，拒绝恢复原基点，加载后核验重建。最多8cells/块，detached缓存上限2GiB，无全网格AD图/大J/大K。保留全部边、面、内部矩和唯一MPC展开。

初版和第一次canonical修复都出现“基础导数符合限值、完整有限CG方向不符合1e-8”的负结果。独立线性层JVP证明必须保留原AD的bias-first累加顺序；独立复数相位见证证明原primal使用phase-left、AD切线使用phase-right。它们数学相同，浮点顺序不同。本地修复后四个真实固定态通过，两个C完整s/pred/ared逐位一致；仍不将此解释为NN优化停滞的唯一根因。
