# V7 相位表示方案：同规模坐标网络学习复包络

本页只定义下一轮的单一候选，**本批没有实现训练器或开始训练**。已知光波的快变化部分用入射相位明确写出，让同样大小的网络尝试学习余下的三分量复包络。它改变网络给有限元积分点提供的场值；完整边、面、内部矩、原 Maxwell 方程和双 Floquet/DtN 边界保持原流程。可能的收益是减少网络用参数描述传播振荡的负担，代价是每个采样点的复指数及新的完整矩/梯度资格。反射、衍射和倏逝场仍可能让包络快速变化，不能预设单载波有效。

## 入射身份、符号和参考点

原实现是 `src/solvers/common_3d_fields.py` 中的 `_mode_basis` 与 `incident_air_plane_wave_field`。时间为 exp(-i omega t)，空气入射采用 vertical_sign=-1，空间相位为 exp(+i k_inc·x)。本 M5 真空波长5nm、theta89°、phi0°、s极化、幅值1；x/y/z 坐标单位为nm，k单位为nm的倒数。

| 量 | 固定设计值或来源 |
| --- | --- |
| k0 | 2pi/5 = 1.2566370614359172 nm的倒数 |
| kx | 1.2564456695248023 nm的倒数，原cfg.kx |
| ky | 0，原cfg.ky |
| kz_inc | -sqrt(k0²-kx²-ky²) = -0.02193134074032823 nm的倒数；沿原正根分支后乘-1 |
| 极化 | 原空气入射s矢量，phi0时沿y |
| 参考点xc | 固定盒中心(0,0,3.75)nm；改变原x=0的相位原点只产生已知常数复因子，由包络承接 |
| 载波数量与参数 | 一个已知载波；k、参考点均不训练、不拟合标签 |
| 网络 | 原3→64→64→64→6、tanh、8966实参数、FP64、seed421001；随机隐藏初始化＋零末层 |

```math
 k_{\rm inc}=(k_x,k_y,-\sqrt{k_0^2-k_x^2-k_y^2}),\qquad
 E_{\theta}^{\rm scat}(x)=e^{i k_{\rm inc}\cdot(x-x_c)}a_\theta(x),\qquad
 c(\theta)=\mathcal I_{h,p,\mathrm{MPC}}^{\mathrm{curl}}E_{\theta}^{\rm scat}.
```

MLP输入仍按盒中心/半宽归一化；相位必须使用原物理nm坐标，不能把归一化坐标直接代入物理k。复输出配对与原规则相同。乘相位发生在所有边、面、内部积分点，在 Piola pullback、orientation、entity owner 和 MPC 之前；不能给 FE 系数乘边/面/单元中心的相位，因为高阶矩是沿整条边、整张面或单元体积的积分。

原 MPC 相位在x周期10nm处为 exp(i kx10)=0.9999981684573771-0.0019139179426754464i，y周期7.5nm处为1。已知载波在物理采样点携带传播相位，原完整矩映射仍仅通过原MPC展开slave一次；不再给矩packet、Phi列或最终c追加相位，也不新增周期惩罚或假设包络必然周期。参考点只提供常数相位，不改变这两个周期相位。资格测试必须检查owner/非owner周期面、非零复数和内部矩，避免把载波的物理点值与slave恢复相位混为重复乘法。
