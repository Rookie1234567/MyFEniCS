# V31：保留独立幅值的块式波动神经空间

本轮仍研究神经方法如何真正解出原三维电磁方程。旧方法每次学习一束局部波后，把束内幅值比例永久固定，以后只能整体放大或缩小这束波。新方法保留束内数值独立的幅值方向，让后续新波加入时，旧波也能重新组合。它增加了可调的线性幅值，同时增加列库、正交化和保存费用。当前模块的即时最优下降可以与旧方法相同；潜在区别发生在后续重新组合，不能把合成例子当成M5收益。

权威为[Review V30](../review_report_v30.md)。M5仍为5nm、384hex/p3、31968独立复FE未知量、40端口的Si/air非可分三维缺口；体和DtN积分q15不改，网络完整边/面/内部矩q30、终态q60。不做W0/W1、全口面、主线接入、传统PC或存储开发，不向其他工作树写入。原50×25×140nm/Si17-120nm/λ0.7完整三维、decimal2e12B和172800s完整冷流程尚未完成。

## 新块机制与资格

完整算子作用后的幅值列先可逆归一化，再做两遍投影、带主元小QR和小R的SVD，固定rcond=1e-12。不逆正规方程、不形成A*A、不使用全FE逆或全局Gram因子。实际点值函数在每个边/面/内部积分点进入原Piola、orientation和一次MPC；保存原波参数及保留幅值的反变换。

复数非Hermitian、重复/近相关/零列/不同尺度、强相消、整块回滚及保存恢复测试通过。实际21方向资格的完整模型映射相对差2.2244767288883195e-15，q30/q60系数漂移5.2434571698989074e-15，对应原算子作用漂移1.3977989399608097e-14。中心方向差分通过独立配对，batch1/8无差；即时下降与旧最优组合差仅舍入量级。这些仅授新实现启动资格，不能代替正式M5场验收。

首个正式固定块已完整落盘，随后JSON重开检查因tuple/list的容器区别误报失败。最小修复比较实际序列化值；真实tuple坐标保存/重开/恢复测试及短实际块补验通过。首个三方向边界复用，旧失败、耗时及source保留，没有重置原六小时预算。

## 长列库的数值秩与保全

逐块独立不保证所有旧块合在一起后仍数值独立。固定控制2991个存储方向的小型R矩阵出现三个约1e-14的奇异值；按原rcond=1e-12只有2988个有效方向。旧读出幅值范数约2.86e11，而完整FE场范数约0.149，说明不同列之间极强相消。一次固定阈值SVD将幅值范数降至约2.09e5，保存场的原残差由0.4766244193变为0.4766820076；这是一项稳定性修复，未求准原方程。
