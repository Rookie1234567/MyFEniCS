## 同起点与两个不同问题

固定mu/h0、原A/f/G和theta0。控制用I，候选用A冻结的M；候选改变阻尼对不同方向的限制，不把muM加进正式loss。

```math
(K+\mu M)s=-g_D,\quad(SKS+\mu I)y=-Sg_D,\quad s=Sy,\quad S=M^{-1/2}.
```

单纯把原I阻尼换坐标则为另一问题，已用独立小型复数模型配对：

```math
(K+\mu I)s=-g_D\quad\Longleftrightarrow\quad(SKS+\mu S^2)y=-Sg_D.
```
