# V21相位FE：准确端口与有限p物理比较

本轮是有限元表示研究：把已知横向快速振荡写进每个FE基函数，让未知系数描述其余变化，仍求完整三维Maxwell。准确端口回代用保存的二进制输入作精确乘积/求和，减少相消造成的算术误差；它不能提高原系数、积分或离散空间的精度。拓扑端口支持则根据“哪些基函数真正在该面有切向分量”构造耦合，避免浮点污染把内部零迹误当非零；没有按幅值删除项。付出的代价是新算子/恢复/物理资格、独立输出和完整费用。NN/ML/Gram均为0。

模型仍是原几何乘7/135，λ0.7nm、真实三维缺口、Si=0.9998851703688496+4.3236152269189515e-6i、双Floquet、340完整模式。G0=6×4×14/336hex，GX560=10×4×14/560hex，固定κ=(8.97461192517716,0,0)rad/nm，体/DtN q15不改；不是旧M5/5nm/40端口，更不是原尺寸完成。


## 为什么算术与迹修复是必要的

端口原方程−Dc+Hα=gp唯一确定散射α。大倏逝通道在原点可能极大，而D与c点积高度相消；整数精确累积后有理数H除法只舍入一次，独立90/110位十进制对全部340模式复算。保存alpha_lu_raw、alpha_old_backsub、alpha_recovered，p3场系数原字节不变。新α引起的Bδα/原rhs范数O3R=7.4880620e-13/E3R=9.9569573e-12，不能把这当全场求解成本或神经增益。

对仿射hex第一类Nédélec元素，面上的切向迹由该面和边的矩唯一决定。真实Basix entity_closure_dofs及方向变换不把内部族混到边/面；独立面节点/切向矩覆盖p3/p4/p6所有6面、非恒等orientation，局部557/558/562确为内部。因而端口按面拓扑支持构造，保留真实面DOF的所有小项；漏一个真实DOF的负控失败，一般具有真实内部端口的合成输入仍拒绝。适用范围是已验证仿射/同族映射，不推广曲面/混合几何。[Basix实体和方向接口](https://docs.fenicsproject.org/basix/v0.10.0/python/_autosummary/basix.finite_element.html)提供元数据，数学/数值证据来自本地资格，非文档直接背书本算例。

首轮p6误用了phase fixture，修正为真正ordinary角色；其次原空气近零背景的归一化组装差1.0106559e-10略超1e-10，限定小fixture用可复算非零全FE制造背景验证准确任意载荷。真实物理空气common资格不改，真实GX560输入背景不改。两次prefix复用避免重跑3次small LU，所有成本仍计。

普通p6最终独立B/D/H端口作用q15/30最大配对差4.275671921747731e-7（B/D/H各自差未单独保存，NOT_RETAINED） >1e-8；这不是OOM/JIT/MUMPS故障，也不是已完成GX560参考失败，真实O6未准入。全部其他native/端口/RHS/任意非零恢复指标≤1e-10：[资格](records/qualification_v21.json)。P6 math negative不再当工程bug重试，依赖完整P6的O6停，P3/P4 scoped候选继续。
