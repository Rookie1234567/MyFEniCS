本轮先保留一份已有电场，再让另一份独立神经网络学习补充电场。旧网络的所有权重和坐标、相位缓冲区保持不变；只有新网络接受更新。这样可以增加可表达的场变化，同时保留旧结果作为起点。代价是多持有一份网络，并在实际输出和审核时计算两份点值。冻结旧场不保证相加后的场更准确，因此最后审核的是合成场。

FTT把三个沿 x/y/z 的一维小网络相乘来表示三维电场。本批只增加一份完整的宽32、rank8修正，持有两份网络共38400实参数，其中19200基网参数全冻结。两份rank8函数之和可有不超过16的连续TT秩上界，但这里分别计算两支；没有构造一个全耦合rank16核心。这个比较同时改变表示容量和参数路径，不能把改善纯归因于rank。冻结控制检验后续隐藏学习的贡献，两条都继承旧基网的真实训练。

## 固定基场与精确方程

唯一基场为 V45 原坐标冻结路线最终第14轮 `W32_R12_IDENTITY_FROZEN/committed_000010.pt`，2029380B，SHA256 `0121d04be3ae7c8fdaed1fefe23462c378dc81fa841ee0751040c7800d2b4978`，source `bda2ef6c5164a59390479662955e8cef358841db`。它已有14轮、42核心访问、25758累计LSMR迭代、137隐藏实际调用，仍是原门FAIL的研究基场。

完整 H(curl) 插值把网络电场转成网格上所有边、面和内部矩对应的系数，用于原 Maxwell 方程验算。新网深拷贝基网的隐藏层、x/y输出和全部缓冲区，只把z输出权重与偏置清零。修正初态严格零，但首个z方向非零；两条路线从同一个保存初态分叉，没有共享可写参数内存。

```math
c_0=\mathcal I_h^{\rm curl}E_0,\quad g=f-Ac_0,\quad
d=\mathcal I_h^{\rm curl}\Delta E,\quad c=c_0+d.
```

```math
Ad-g=A(c_0+d)-f,\quad
J_\Delta=\frac{\|Ad-g\|_2^2}{2\|g\|_2^2},\quad
R_{\rm original}=\frac{\|g\|_2}{\|f\|_2}R_\Delta.
```

g是方程残差的相反数，不是准确电场误差，也没有直接当成电场使用。资格阶段由原A生成g一次；准备及两条训练只读取已保存、hash绑定的g。原action.f未修改。训练分母为norm(g)=0.1043574223800681，正式native分母为norm(f)=0.29104200262261154，两者分别保存和核验；原总场方程仍用自己的原始总载荷分母。

端口直接从合成c按原公式恢复，背景只加入一次。每支网络各施加一次已知横向相位，加和外不再乘相位；原MPC约束只展开一次。H由合成有限元电场的curl计算。磁盘重开两网后使用旧逐点MLP路径先相加，再独立完整插值，actual与producer分别评分。
