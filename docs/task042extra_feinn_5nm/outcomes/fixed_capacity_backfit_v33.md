## 重学旧波，所有幅值随之重新选择

旧方法新增波后冻结它的方向。本次不增加列，而是取出一个旧波块，重新学习连续波矢，再让其余旧波一起调整复幅值。它检验固定内存容量下的特征可否进一步改善；稳定最小二乘和QR维护并不是神经贡献，全部都要计费。控制同样允许改波矢，只使用不求梯度的固定模式搜索，所以对照隔离的是更新策略。

原散射点值模型使用全域及粗/中/细窗口：

```math
E_s(x)=\sum_j\chi_j(x)\sum_{\ell} e^{iq_{j\ell}\cdot(x-x_j)}p_{j\ell}.
```

q是实连续波矢，单位rad/nm，p是三分量复幅值；不是给FE系数乘中心点相位。全部点值先经完整矩映射。令U_F含全部非活动块，活动块为C(q)=C_raw(q)T，T、窗口、原列掩码在一个试探内固定。

```math
B_F=A U_F=Q_F R_F,\quad P_F=I-Q_FQ_F^*,\quad r_F=P_F f,\quad Z=P_F A C(q).
```

```math
b=\arg\min_b\|Zb-r_F\|_2,\qquad a_F=\arg\min_a\|B_F a-[f-A C(q)b]\|_2.
```

```math
c=U_Fa_F+C(q)b,\quad r=f-Ac,\quad \phi=\frac{r^*r}{2f^*f},\qquad d\phi[\delta q]=-\frac{\mathrm{Re}\{r^*A[dC[\delta q]]b\}}{f^*f}.
```


Q_F必须删除活动块；若拿含活动块的全Q投影，会错误投掉自身方向，已作独立错误全Q负控。复幅值导数由局部最小二乘驻点抵消；q/k0坐标的真实梯度含k0链式因子。经济型QR删除/插回、带主元小QR/SVD固定rcond1e-12，活动補空间每次访问只建一次，没有A*A、N×N投影、大J、全FE逆或Gram逆。

## 原点值和固定变换保真

原完整Nédélec边/面/内部矩、Piola、orientation和MPC仍只展开一次。强复相消使用每列补偿累加，幅值差量问题是原最小二乘的等价写法；相位微差采用exp(iq0·x)expm1(iδq·x)而非相减两个接近的指数。全部原T和原保留列固定，没有释放旧丢弃方向凑更多容量；实际网络以原q和完整反变换独立重建，不用理想投影场交付。

每个接受边界原子保存原q/T/全部幅值/c/r/匹配小R/QR更新序列/队列/RNG/预算。trial不能覆盖committed；原残差不增和约化/完整原作用配对≤1e-10才接受，插回QR不可靠则恢复整套状态。初始化零态原残差配对最坏约7.15e-11，小/全原作用约4.29e-13，实际短块保存重建约8.93e-13；真实数学资格的全部绝对量、三步长差分和四尺度已保存。
