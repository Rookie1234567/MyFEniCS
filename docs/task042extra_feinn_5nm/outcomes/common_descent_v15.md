## 参数小步与两项能量

P表示实参数方向，X/GX是完整FE场方向及旧G作用，Y/WY是旧A方向及旧G逆作用。所有这些作用已保存，本轮新增作用均0。先在参数空间做列归一化QR和小R-SVD，取得P T的正交列；不能用场空间的G正交替代参数步长。固定半径为两态0.008553653337049638/0.008560515209936437，不扫描。

```math
\rho=10^{-3}\max(\Vert\theta\Vert_2,1),\quad
\delta\theta=\rho PTu,\quad\Vert u\Vert_2\le1,\quad
\delta c=\rho XTu,\quad\delta r=\rho YTu.
```

F是相对当前G场误差能量，R是相对当前G对偶残差能量，起点均1。G同时衡量电场与curl；对偶残差衡量原方程作用在固定测试空间上的不平衡。二者不是同一指标，能量下降0.1%也不等于场范数下降0.1%。这些当前态分母只用于诊断，不替代训练固定RHS分母。

```math
F(u)=\frac{(e+\delta c)^*G(e+\delta c)}{e^*Ge}=1+2a_F^Tu+u^TH_Fu,
\quad R(u)=\frac{(r+\delta r)^*G^{-1}(r+\delta r)}{r^*G^{-1}r}=1+2a_R^Tu+u^TH_Ru.
```

主rcond1e-10与固定敏感性1e-12各运行一次；两档均保留PDE8秩8、ALL16秩16，没有截断，物理步和目标相同。完整奇异值、列尺度、参数正交与重构缺陷见[结果](records/common_descent_results_v15.json)，不选择较好截断结果。

## 可行上界、可重算下界

```math
m_*=\min_{\Vert u\Vert_2\le1}\max\{F(u),R(u)\},\quad L\le m_*\le U,
\quad U=\max\{F(\widehat u),R(\widehat u)\}.
```

```math
H_\lambda=\lambda H_F+(1-\lambda)H_R,\quad
a_\lambda=\lambda a_F+(1-\lambda)a_R,\quad
L=1-\mu-a_\lambda^T(H_\lambda+\mu I)^\dagger a_\lambda.
```

保存lambda/mu、谱、伪逆解作用、值域/驻点/互补缺陷、原向量交叉项与界差；checker用原数组重算，并独立解小证书矩阵，不再次优化。舍入余量是披露的保守数值估计，不是区间算术严格证明。实质负曲率/错误分母/身份冲突不会以epsilon或shift掩盖。
