# V39：利用一维结构补完FTT优化的真实结论

本轮解决的是“同一个小神经模型却在大量三维点重复算一维核”的执行成本问题，不改变原方程，也不假设原材料可分。结果是等价完整工作明显加速，原定Adam→L-BFGS实际完成；原方程和全场依然FAIL。完整结果见[Response V39](../response_v39.md)，本页说明机制、证据与投入决定。

本支只做神经。原M5为5nm、384个仿射hex、h1.25nm、第一类Nédélec p3、31968个独立复FE系数和完整40端口，Si/air真实三维缺口、原背景、双Floquet和DtN保持。体/DtN q15、网络完整矩q30、独立q60不改；没有新rank、载波、材料、loss、权重或优化器扫描。

FTTNN仍由三个小网络分别产生随x/y/z变化的复矩阵，再连乘形成三维复场，ranks=(1,8,8,1)、9072实参数；Chebyshev T0..T18控制同秩、9120实系数。本轮没有换模型，而是把相同的一维坐标核只计算一次，再准确重排完整边、面和内部矩的有限和。它减少重复核评价和反传，代价是新增索引/缓存/矩分解；材料始终留在原完整A中，不假设三维缺口或材料可分。

## 等价映射的适用边界

每轴唯一物理节点142/107/143。重复节点先按完整参数/buffers、model_kind、坐标/用途/dtype绑定数值core表，矩的复共轭余切通过scatter-add累计后只对唯一轴节点做微批AD。接受参数更新、trial或恢复使动态缓存失效；原矩、方向、Piola分量混合和唯一owner仍完整处理，只展开一次MPC。

原p3参考测试多项式逐项转换为degree≤2的Legendre多项式索引的有限和，完整复interpolation条目全部核对，不作SVD截断、幅值裁零、材料低秩近似或积分点替换。19实体（12边、6面、1内部）共有的一维线性泛函只在字节一致时复用，原小非零系数仍保留。每局部有界张量完成三分量矩后施加原Piola/方向，不能把系数中心点相位代替积分点函数。

M5现场384cell均为已资格化轴向仿射映射，最大坐标规范化舍入差约4.44e-15nm、仿射相对差约1.50e-15；完整旧/新点映射对照通过。这是该case的浮点等价资格，不是任意hex自动可分或逐位轨迹定理。非支持行和真正斜映射fixture走原准确点有限和，不结束整份映射、不改网格。原旧StreamingMomentMap作为独立对照和最终重建保留。

规划不存N×P、N×r²、大J、全网格AD图或旧U/Q；最多8cell、轴核AD微批≤512，固定稀疏线性映射的共轭转置保留。静态索引/多项式/矩表约1631140B，动态core438144B，逐微批AD明确释放，新增缓存/AD规划远低1GiB；这些对象字节不是整树峰。
