# V30：按原方程学习新的局部波动函数

本支只做神经求解研究。新方法每次用尚未满足的原方程寻找一个局部波动函数，学习其连续波矢和复向量幅值，再将函数冻结，加入此前累计的空间共同求解。这样改变的是实际可用的神经函数空间；完整边、面和内部有限元矩、原材料、双 Floquet 及 DtN 均保留。它仍在原 p3 有限元空间内，不能消除该空间自身的离散误差。

执行权威为 [Review V29](../review_report_v29.md)。历史 tanh/GN/固定末层以及 W0/W1 辅助研究关闭，历史全部负结果和成本不变。本页随真实运行追加，不以实现或测试通过冒充数值通过。
