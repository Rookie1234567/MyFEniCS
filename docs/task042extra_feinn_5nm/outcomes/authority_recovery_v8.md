# Task42extra V8：准确 p4 参考恢复与阶次敏感性

本轮已经得到合格的小型 M5/p4 参考，分类为 `P4_REFERENCE_QUALIFIED`。同一几何从 p3 改到 p4 后，场、复通道和功率变化超过预登记的小变化门限，分类为 `P3_P4_SENSITIVITY_OBSERVED`。这证明一次阶次变化值得关注；尚未证明连续解、网格尺寸或端口截断收敛。旧 p3 神经候选没有解出原 p3 方程的事实保持不变。

## 1. 定位到哪一步，修复改变了什么

有限元装配要把各单元的局部方程放入同一个全局方程，并正确连接周期边界。本轮绕开慢的 MPC 稀疏装配调用，直接用已资格化的局部张量和完整约束展开映射完成相同的全局求和；没有删去内部系数、换积分、加吸收或近似周期关系。

| 阶段 / measured | 原路径证据 | 处理及结论边界 |
| --- | --- | --- |
| form/JIT 调用 | 0.001683193 s 返回 | 本次已有任务缓存下很快；不能外推冷缓存 JIT 时间 |
| MPC assemble_matrix | begin 后 300 s 剖析窗口内没有 end | 瓶颈定位到该调用，内部子原因仍 unknown；不是 MUMPS 分解用时 |
| 首次 profile 写日志 | 复杂模式字段不能直接 JSON 序列化，2.531118 s | 保留失败原记录；增加显式转换，仅重试短剖析 |
| 等价 CSR 装配 | 75304 行，32891168 非零，658124580 B payload | 有界单元批与预分配 COO/CSR 合并；只移除精确结构零，不按幅值截断 |
| numeric | 14.890155 s，新增一次 | 一次成功后不再分解；没有使用静态凝聚或扫描 ordering |

```math
V=\sum_K P_K^*F_KP_K,\qquad
M=\begin{bmatrix}V&B\\-D&H\end{bmatrix}.
```

这里的 P_K 是原全 FE 约束展开，不再额外乘方向或 Floquet 相位。CSR/rhs/排序/hash 先保存。CSR 与 packet.apply 相等只作为自洽检查；独立性另由原 Basix 基函数的值和导数直接积分核、DOLFINx 线性形式审核提供。该积分核没有读取用于装配的 F；共享的几何、材料、Basix 元、方向/MPC 约定和 DtN 耦合是明确共同输入。

8-cell p4、M5 p4、M5 p3 各三个非零复向量的独立体项/增广/伴随配对均低于 1e-10，内部系数非零。M5 p4 最大独立体配对约 1.89e-15；原 p3 已保存参考的增广残差 6.79e-12、独立总场残差 3.28e-12。未重求 p3。
