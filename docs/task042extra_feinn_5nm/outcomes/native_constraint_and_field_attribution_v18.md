# V18：原残差受约束方向与保存场退化归因

本批回答两个具体问题：原八个方向能否改为降低原方程不平衡且不增原加权残差；旧场误差增大是否主要集中于界面或周期邻层。A 提供稳定可行的线性候选，B 完成此前未运行的实际保存场积分，C 完成两态实际网络见证。C 的原残差和场误差均改善，但两态加权残差增量超过预登记门。因此不获得两态局部机制支持，不解冻主求解器或生产初始化，不自动继续训练。

对象固定为 M5：5nm、10×7.5×10nm、Si/air非可分缺口、384hex、p3/q15、31968独立复FE、40端口、8966实参数。所有原场、材料、入射/背景、Floquet/MPC、模式排序、单位与参考沿 [设计](records/campaign_design_v18.json)。参考为已有同p3准确离散解，不是连续极限。旧M3600较好中期、Mfinal退化及所有旧失败/UNKNOWN保留。

## A：固定空间的新目标及独立证书

旧R最小方向在两态都加大原残差；这次在同八维参数空间内换为直接减小原残差，并要求原R不增。只解小凸问题，未调用新的FE/网络/算子作用。参数步幅和两档rcond固定，没有扫权重、半径或截断；标量乘子由约束求根决定。构造进程仅解释原P/Y/WY/r/qr/theta，参考字段文件只校验hash，X/GX/e/Ge延后到另一个评分进程。冻结账本记录fsync后候选hash及真实PID，评分与独立checker不反馈方向。

N/R/F 是相对各态原点的三种能量比，越低越好，原点均为1。F仅在候选冻结后评分。独立checker用原数组直接内积重算，并用小矩阵、非负乘子、半正定/值域/驻点条件给保守下界；不调用producer或优化器。
