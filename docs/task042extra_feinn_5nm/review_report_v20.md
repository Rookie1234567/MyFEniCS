## 3. 审阅端新增归因：支持修复，但尚不授予通过

### 3.1 p6 内部端口：结构性零迹假设有具体定位

“单元内部未知量”只描述单元里面的场，其 Nédélec 基函数在边界上的切向分量理论上为零；因此纯端口积分应只耦合相应面及其边的自由度。严格内部消元利用了这个结构，而不是允许任意小非零量。

从已保存原包独立定位：B、D内部项分别范数1.3099141613262974e−11、1.4812270653356738e−12，占全块3.93010e−14、4.10166e−14；120个内部行只落在 **40个单元的局部基函数557、558、562**，模式均属top。这支持检查基函数零切向迹／仿射坐标和方向变换的浮点污染，**没有证明可以按幅值删除它们**。同一Basix浮点基函数用于两套求积时，两者相符也不能证明理论零已正确实现。

下一步出口是根据面闭包的拓扑自由度构造端口迹，而非将2264项设置一个阈值后删掉。Basix 0.10的[实体自由度及方向变换接口](https://docs.fenicsproject.org/basix/v0.10.0/python/_autosummary/basix.finite_element.html)提供映射信息；**本算例是否满足对应零迹条件是待验证推断**。若映射／曲面几何／约束实际使内部项具有真实支持，此出口不成立，不能强套；本批不另开发含任意内部端口的通用Schur后端，以免重复dot的工作。

### 3.2 原端口恢复：求和误差存在，但不是单一原因

原增广方程端口行是 −Dc+Hα=g_p，因此给定全部 FE 系数 c 后，端口有唯一回代 α=H⁻¹(g_p+Dc)。原实现既保留全局LU所得α，又用普通complex128点积从c回代，二者比较。在强倏逝模式中，参考原点的α很大而边界实际振幅很小，极小的边界误差会变成很大的原点误差。

| 仅用longdouble累积后的相对差 | 2.4169987226e−4 | 1.5566795157e−3 |

| c完全不变、采用精确α的体方程残差 | 9.9267090293e−12 | 8.5358426298e−11 |
| 同一操作的total体方程残差 | 1.2689622862e−10 | 6.8706011070e−12 |

这里精确法对**保存的binary64输入**作整数累积及有理数除法；另一独立90位十进制实现对全部340通道得到相同complex128结果。它不提高原FE系数或积分本身的精度。审阅没有写出新合格场、改变旧α或改判V20。部分主导误差通道的点积取消比约1.7e14–7e14，longdouble对精确回代的单通道差仍可达约1e−5；所以“升到longdouble然后重跑”已经缺乏依据。[准确点积的原始研究](https://www.tuhh.de/ti3/paper/rump/OgRuOi05.pdf)支持区分乘积与累积误差，但不为本任务的物理精度背书。

**允许尝试的新算法是最终端口的准确回代，不是给旧LU端口放宽门。** 原LU输出、旧回代、准确回代三份量及差异全留；采用新输出后，重新验证实际输出的完整未凝聚方程、独立物理弱式、背景与340通道。独立checker不能调用同一个producer回代函数，也不能仅作“算出来再与自己相减”的检查。原坐标恢复1e−10、物理模式1e−4及近零分母1e−12都不变，不能换成β范数。
