### A，P0：原方程优先、原对偶残差不增的唯一局部干预

通俗地说：旧算法为一个加权残差挑出的“最好方向”反而加大了原方程的不平衡。这次在**完全相同的八个已有方向和原参数步幅**内，直接减小原方程不平衡，同时禁止原加权残差恶化。只求解至多8维的小凸问题，代价很小；代价之外的限制是它仍只是原网络的局部线性模型，没有新的表达能力或全局解保证。

用原PDE8与原rcond=1e-10为主，1e-12只做既定数值敏感性，不择优；两态各做一次，共4个小配置。令Q=P T为物理参数正交基，δθ=ρQ u、ρ=1e-3 max(norm(theta),1)，δr=ρY T u，参数球norm(u)≤1。N和R的定义及问题为：

```math
\begin{aligned}
N(u)&=\frac{\|r+\rho YTu\|_2^2}{\|r\|_2^2},\\
R(u)&=\frac{\mathrm{Re}[(r+\rho YTu)^*(q_r+\rho W_YTu)]}{\mathrm{Re}(r^*q_r)},\\
&\min_{\|u\|_2\leq1,\;R(u)\leq1} N(u).
\end{aligned}
```

WY是已存G逆Y。正式native另用原norm(f)=0.29104200262261154，不把N的当前态分母换成正式分母。**这不是V15的min max(F,R)，不改变旧F/R共同下降裁决。** 旧PDE8的R最小值仅0.999782594069/0.999588352612且已在原球内，原≥0.1% R下降本就不可达；本批不以R不增来追认旧门通过，而是新增“native目标能否在保留原R约束下改善”的反事实诊断。原两条R最小方向仅作保存对照，不重算/缩步修复。
