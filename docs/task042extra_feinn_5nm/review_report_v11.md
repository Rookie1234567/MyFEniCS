## 2. 比较对象与不变的验收标准

FEINN 的工作是让网络输出一个连续坐标场，再通过边、面和单元内部的积分，把它变成完整有限元系数。训练减少这些系数代入原离散方程后的不平衡量。这里的有限元场才是验收对象；网络原始连续场、训练 loss 和优化器返回成功均不能代替它。

## 4. V11 最新证据：改善与退化同时成立

### 4.1 不是八次超参数搜索

“八组”指四层网络各自的 weight/bias。V11 在共同 phase75 状态上，用每组 3 个固定随机方向估计曲率，冻结一个分组对角矩阵 M，只运行 **identity I 与该 M 两条路线**。曲率跨度约 2,226,256 不是精确条件数。起点欧氏残差梯度与对偶残差梯度余弦 0.0551022 是接近正交，不能写成负相关或全程冲突。

阻尼 GN 用局部线性化估计一步更新，并用真实 loss 检验是否接受。V11 改变的是“哪些参数方向走起来更贵”的阻尼项，解 `(K+μM)s=-g`；它不是仅换坐标而完全不改轨迹，也不是改物理方程或添加边界损失。两路起点、μ、h0 和固定 buffers 相同，均禁止低秩预条件器。

## 5. 瓶颈裁决与源码依据

原算子包括复材料、传播相位和开域端口，并不是处处正的能量矩阵。G 则人为选取正的“电场加旋度能量尺子”，用于测量弱残差。它能稳定定义 loss，但目前没有证明该 loss 对本散射问题的场误差具有足够紧的统一控制。论文的正质量 H(curl) 模型、Dirichlet 边界与线性化测试空间不同，不能直接把其保证移到本问题。[Compatible FEINNs，§2.2、§2.3、§2.7–2.9](https://arxiv.org/html/2411.04591v2)

用 c_ref 表示准确 p3 散射系数，本分支实际关系为：

```math
A=V+B H^{-1}D,\quad f=g-BH^{-1}g_p,\quad
r=Ac-f,\quad e=c-c_{ref},\quad Ae=r-r_{ref}.
```

```math
G=C^*(M_E+\ell^2K_{curl})C,\quad \ell=5\ {\rm nm},\quad
L_D=\frac{r^*G^{-1}r}{2f^*G^{-1}f},\quad
E_G^2=\frac{e^*Ge}{c_{ref}^*Gc_{ref}}.
```

这里 C 是 Floquet 约束映射，H 是原端口归一化块，不能与消元后端口块混淆。A 的作用不存全局 Maxwell CSR，但 G 的稀疏准确因子仍是 `RESEARCH_ONLY_GLOBAL_RIESZ_FACTOR`。求解 G 的误差小，仅说明所选尺子计算准确，不说明这把尺子足以引导网络求解。
