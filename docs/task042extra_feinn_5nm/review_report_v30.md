## 2. 有依据的下一机制：保留模块的独立线性幅值

### 2.1 源码中实际发生的限制

`neural_wave_greedy.variable_projection` 对一个含 w 个波的模块先构造最多3w个完整 FE 幅值列 C(q)，并以小型SVD求出向量 p。实际 `run_greedy` 随后只把 `C(q)p` 经独立点值映射后交给 `space.add`；保存时 p 与 q 一起冻结，以后只有一个全局复系数 a 可以缩放整个模块。

```math
c_{\rm old}=\sum_b a_b C_b(q_b)p_b^{\rm frozen}.
```

因此，14520个波不是14520个独立可重新组合的波动系数，更不是43560个独立复幅值。当前全球线性自由度只有3127。它是明确的模型选择，**不是已经证实的程序错误，也不是已证实的唯一失败根因**。

新候选保留被数值秩允许的独立分量：

```math
c_{\rm block}=\sum_b C_b(q_b)b_b,
\qquad b_b\in\mathbb C^{3w_b}.
```

同一组 q/窗口下旧场属于新空间。新增列只要保留旧空间并稳定最小二乘，就不应提高完整 native 最小残差。但新空间更大，可能只增加费用而无有效收益；这需要真实对照，不能事先写成突破。

**关键限定：同一次新模块插入时，原最优组合可能已经实现整块的全部即时下降。** 若 Z 是相对既有空间正交化后的 AC，原 p 给出 ZZ†r，那么只加入 z=Zp 也能消除同一份当前残差投影。块保留的潜在收益在于以后的模块加入时仍能重新组合旧分量，而不是“每块第一次就必然更好”。测试必须覆盖这点，不以即时无差异错误否决或虚构收益。

可用三维小代数例说明：A=I，f=e1+e3，第一块[e1,e2]。即时最优方向只有e1；随后加入e2+e3，旧单列累计空间的相对残差为0.5，保留整块则可为0。此为说明机制的合成例，绝非 M5 证据。

### 2.2 与论文的关系

参考 [DGPWNN](https://arxiv.org/html/2506.09309v1) 的波动函数/自适应空间及 [variable projection](https://arxiv.org/abs/2201.09989) 的非线性特征与线性系数分离思想。论文并未证明本原生 Nédélec/DtN 欧氏残差迁移会收敛；本报告的块保留是项目内待验证的修改，不把论文的正定变分界或小系统条件数保证搬过来。不是重写 DG、另做通用 PC，亦不是回到 V5 的固定195维末层。
