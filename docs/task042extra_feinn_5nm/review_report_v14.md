### B：求“小步内能否同时改善”的数值上下界

这里的“小步”只改变保存的线性近似，不更新真实网络。先在**参数空间**对所选P做稳定QR/SVD，取得变换T使P T列正交；禁止误把场空间G正交当参数步长。用真实秩和变换拉回所有列，实数u满足norm(u)≤1：

```math
\delta\theta=\rho PTu,\qquad
\delta c=\rho XTu,\qquad
\delta r=\rho YTu.
```

用原数组内积构造两个最多16维的实对称二次式。F衡量相对当前G场误差能量，R衡量相对当前对偶残差能量；二者起点均为1，数值越小越好。此处当前态分母只服务于诊断，**不替换训练的固定原RHS分母**：

```math
F(u)=\frac{(e+\delta c)^*G(e+\delta c)}{e^*Ge}
     =1+2a_F^Tu+u^TH_Fu,\qquad
R(u)=\frac{(r+\delta r)^*G^{-1}(r+\delta r)}{r^*G^{-1}r}
     =1+2a_R^Tu+u^TH_Ru.
```

GX、WY、Ge、qr都已保存；公式不授权新G作用或G求逆。取复内积的实部对应实参数，不忽略共轭。检查对称/半正定与操作尺度；实质负曲率、非有限值或数据身份冲突停止受影响状态，不用epsilon或大对角shift掩盖。

每个“态×方向集合”固定比较零步、残差最小点u_R、场误差最小点u_F及共同目标点。u_R先生成并保存hash，然后才评价F；其中仅PDE8的u_R构造可标无标签。ALL16的u_R也因方向来源而暴露参考；u_F与共同目标点使用参考，均只能标 `REFERENCE_EXPOSED_LOCAL_ORACLE`。共同问题为：

```math
m_*=\min_{\|u\|_2\le1}\max\{F(u),R(u)\},\qquad
L\le m_*\le U,\quad U=\max\{F(\widehat u),R(\widehat u)\}.
```

不能仅凭小优化器success宣称“不可共同改善”。应保存一个可行点给上界U，并给可重算的下界L。可用两目标非负凸组合与球约束乘子：0≤λ≤1，μ≥0，Hλ=λH_F+(1−λ)H_R，aλ=λa_F+(1−λ)a_R。若Hλ+μI半正定且aλ处于其值域，则：

```math
L(\lambda,\mu)=1-\mu-a_\lambda^T(H_\lambda+\mu I)^\dagger a_\lambda
\ \le\ m_*.
```

上述小矩阵伪逆由稳定分解/解作用计算，不形成全局FE矩阵或逆。保存λ、μ、谱、值域缺陷、球约束/驻点/互补缺陷、原向量复算值与U−L；数值容差和可能的舍入余量必须披露。这是有限维小问题的数值证据，不宣称区间算术级严格证明。λ仅用于求证这一个诊断问题，**不是可反馈训练的参考调权参数**。

允许最多 **64次λ评估/每个配置**，每次内层球约束标量求根最多80步；2态×2集合×最多2个rcond共8个配置，最多512次小问题评估。复用端点作为u_R/u_F，不能追加权重网格、半径网格或求解器轮换。无需新增依赖；当前NumPy/SciPy的小型分解足够。数值不收敛保留区间和UNKNOWN，不自动扩大预算。
