## 3. 新假设、数学边界及审阅预检

### 3.1 相位进入基函数，完整 Maxwell 方程不作近轴近似

通俗地说，把已知的横向快速振荡精确写在每个基函数里，只让有限元系数描述余下的变化。这样可能用较少的多项式自由度描述同一物理场；代价是重新资格化体弱式、周期约束、端口耦合和完整场恢复。**不能删掉二阶项、改成单向传播、标量/二维求解或只计算包络强度。**

只冻结一个横向载波：κ=(kx,ky,0)，kx/ky由正式0.7 nm入射决定，原点固定为(0,0,0)，不拟合相位、不用标签选择载波。设 g=exp(iκ·x)：

```math
E_h=g u_h,\qquad V_h^{g}=g V_h^{\rm per},\qquad
\nabla\times(g u_h)=g\bigl(\nabla\times u_h+i\kappa\times u_h\bigr).
```

原空间是具有物理 Floquet 相位的普通 Nédélec 空间；候选中的 u_h 是周期 Nédélec 场，仍含三个复分量、边/面/全部内部矩。κ仅横向，z方向入射/反射传播都保留。上式是连续函数恒等式；**有限维的 g V_h 并不等于旧 V_h，也不是在旧自由度上乘一个对角相位矩阵。** 不能用旧 A、旧 G、旧参考身份或“同离散”标签。

体弱式用完整的修正旋度，复测试仍取共轭：

```math
\begin{aligned}
\mathrm{curl}_{\kappa}u&=\nabla\times u+i\kappa\times u,\\
a_{\kappa}(u,v)&=\int_{\Omega}\mu_r^{-1}\mathrm{curl}_{\kappa}u\cdot
\overline{\mathrm{curl}_{\kappa}v}
-k_0^2\epsilon_r u\cdot\overline v\,d\Omega
+a_{\partial\Omega}(g u,g v).
\end{aligned}
```

物理入射、材料、频率及 DtN 导纳不变。仅 u 的周期映射去掉已提取的相位；**不得把物理 cfg.kx/ky 清零**。原第(m,n)端口的物理横向波数仍是 kx+2πm/Lx、ky+2πn/Ly；在包络耦合积分里公共相位相消，指数剩倒格矢，极化、上下方向、参考面、单位和 H 块仍用原物理定义。入射/背景 RHS、total/scattered 仿射关系也必须一起变换。

物理后处理使用 E=g u，curl(E)=g curlκ(u)，H按原单位从此物理curl恢复。只对 curl(u) 作后处理会给错磁场和功率。g连续且非零保证相应 H(curl) 贴合；但**这不自动证明所选离散空间的 exact-sequence、无伪模或高频稳定性**，不得借 compatible FEINN 名称跳过独立见证。

可参考[平面波边元原始研究](https://doi.org/10.1016/j.advengsoft.2008.03.004)关于把传播函数纳入边元及振荡积分成本的讨论；该论文并未给本任务的完整散射、2TB或48h保证。本处只用一个公共横向相位，不复制多平面波 PUM。原[compatible FEINN论文](https://arxiv.org/html/2411.04591v2)的正 H(curl) 模型也不构成这里不定开放 Maxwell 的收敛保证。[双周期 Maxwell–DtN 原始研究](https://arxiv.org/abs/1811.12449)仅作边界与离散误差分开处理的理论依据；本批不移植其自适应算法。
