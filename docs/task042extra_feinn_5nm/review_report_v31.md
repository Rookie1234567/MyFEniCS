## 2. 本次发现：区分源码事实与因果假设

### 2.1 源码事实

[neural_wave_greedy.py](../../src/solvers/neural_wave_greedy.py) 中：

- `patch_inventory` 用域长/分段数作为窗口半径；粗(2,2,2)、中(4,3,4)、细(8,6,8)。例如 z 半径依次为5、2.5、1.25nm。级别变大是支持变小，不是全域交流增强。
- `level=max(...,1 if m>=32,...,2 if m>=128,...)` 使后续新候选只来自最细库存；旧粗列仍保留，但不再学习新的粗尺度函数。不存在持续同时竞争的全域/多尺度候选池。
- `select_patch` 按各窗口 owner 行上的原残差平方和排序，只在前8个窗口中循环。这个启发式不是新方向对完整方程的敏感度；须核对重复row/owner口径，不能未检查就声称有重复计数bug。

这些是已读源码行为，不是已经测出的“底部必然没有函数”。两候选T一致、散射幅值几乎未恢复，支持检查覆盖和传播路径，但**相同T不推出端口映射为零，也不排除残差度量/条件性造成的困难。**

### 2.2 为什么应该按试探方向影响检查，而不是只看残差在哪儿

定义原残差 r=f-Ac，目标 J=0.5*r^*r，则：

```math
dJ(c)[v]=-\mathrm{Re}\{v^* A^*r\}.
```

因此试探系数的敏感度由 A* r 给出，不能把测试残差 r 的同位置数值自动当成可修改场的位置。两维说明：A=[[1,4],[2,0]]，r=(1,0)。方向e1可消去残差能量1/5，方向e2可消去1；但仅看r第二项为零会错过e2。此为代数反例，不是对M5的归因证明。

对候选完整矩块 C、已有原作用正交空间Q，继续使用原算法的准确得分：

```math
Z=(I-QQ^*)AC,\qquad S(C)=\|P_{\mathrm{range}(Z)}r\|_2^2.
```

A* r只用于便宜的候选预选，最终跨窗口/尺度比较用这个原得分和真实残差；有效秩截断后用实际保留投影，不错误复用全Q。**不改A/f，不换训练loss，不引入原A逆或全局Gram逆。**

多尺度同时存在的神经表示可参考 [multilevel FBPINNs](https://arxiv.org/abs/2306.05486)：该研究支持检查局部子域之间的全局交流，但并未证明本高频复数Maxwell迁移可收敛。本任务仍使用既有兼容矩和波动模块，不实现另一套PINN或Schwarz PC。
