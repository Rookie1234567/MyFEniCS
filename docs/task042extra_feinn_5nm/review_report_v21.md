## 3. 本次审阅新增的两个可区分解释

### 3.1 总场失败已定位到系数相加舍入，不必再factor

总场系数是散射系数加背景。两者相加只舍入约机器精度，但某些倏逝模式的原点投影非常敏感，会把这点误差放大。审阅对保存的binary64 D/H和全部340模式做独立110位分解，包含系数相加、两次端口输出舍入、端口相加及原端口载荷五项；gp实际为0。

| 状态 | 总系数相加相对舍入 | 它造成的原点恢复相对差 | 保留未舍入仿射和时的投影差 |
| --- | ---: | ---: | ---: |
| O3R | 2.85310e−17 | 3.14135214499e−7 | 2.81225e−16 |
| E3R | 4.22680e−17 | 1.58808230122e−5 | 5.17171e−17 |
| E4 | 4.24090e−17 | 4.28610468926e−4 | 9.83198e−17 |

系数相加项在总缺陷方向上的投影比均约1，其余端口舍入项相对总α范数约1e−16或更小；五项闭合相对误差<5e−106。**这定位的是保存数据上的算术原因，不是对D/H物理积分或场准确性的证明。** 简单提高点积累积精度、再换边界坐标或增加求解迭代不会恢复已在相加时丢掉的信息。

可实施的修复是把一次相加舍掉的低位也保存：两个complex128数组 `total_hi,total_lo` 共同、精确定义同一组完整FE系数，逐实／虚分量使用误差自由加法，满足 `total_hi+total_lo = c_scattered+background` 的精确实数含义。它不增加FE空间或改变Maxwell方程，只改变总场输出表示；代价是额外一个全FE向量及读取／验算工作。旧 `c_total` 单数组和失败不改。新格式若被消费者过早合回一个double数组，问题会重现，必须作为负控拒绝。

### 3.2 q15不自动适合端口：体积分稳定不等于面投影稳定

面端口包含“有限阶多项式×振荡指数”。提高体场积分阶数可以准确比较两份已经算出的场，却没有重新检查生成这些场的端口积分。V21完整模型的独立B/D/H配对仍用q15；小资格仅36通道，其p3/p4通过不能覆盖真实340通道的相位跨度。

审阅利用[NIST的Legendre–球Bessel积分恒等式](https://dlmf.nist.gov/10.54.E2)，计算实际面宽、模式频率和阶次上的独立一维见证。平面仿射六面体的切向基函数可展开成两方向的多项式乘积，从而用低维解析矩代替大量振荡求积点；这是一条明确的端口积分算法，不是学习器或新的物理近似。

```math
\int_{-1}^{1}P_\ell(t)e^{izt}\,dt=2i^\ell j_\ell(z),\qquad
z=\tfrac12(k_{\mathrm{mode},t}-\kappa_t)h_t.
```

| 真实跨度上的单项见证 | 名义q15／8点Gauss绝对误差 | 16点对解析式的最大误差 |
| --- | ---: | ---: |
| AIR8普通p6，x面、m1、ℓ6 | 3.89612712e−7 | 2.67e−15 |
| G0相位p3，m−8、ℓ3 | 2.14713220e−6 | 4.45e−15 |
| G0相位p4，m−8、ℓ4 | 1.11660588e−5 | 4.45e−15 |
| GX560普通p6，m8、ℓ6 | 1.51104549e−4 | 3.45e−15 |

G0最坏实际通道m6对应的p3/p4单项误差为5.87050e−8／4.11363e−7。上述量是**单个标准多项式矩的绝对误差**，不是已复算B/D/H、不是相对场误差，也没有证明167倍模式差由求积独自造成。它们与小p6失败同量级，并支持下一批用真实保存场做因果区分，而不是直接提高p或训练。16点见证通过也不是全原尺寸求积规则；原尺寸面跨度必须另验。
