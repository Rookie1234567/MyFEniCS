# DtN CGS2 结果归档

归档日期：2026-10-30。按用户要求停止数值研究，整理现有结果；本次只核对小型证据，不启动求解或训练。后续迭代方法研究暂停，转入用户拟定的 surrogate 新任务并等待新几何细节；本报告不安排任何后续数值启动。

**结论：** 固定 rank64、FGMRES(300) 的四个新 `refine_always`（CGS2）运行均正常完成代数求解，分别为 **102、163、152、152 步**；各自保存解均通过独立原矩阵残差审计。三个正常旧基线分别为 395、457、789 步。旧 λ=0.84 / 836 例是中断运行，不能作为正常收敛基线。

## 方法与指标

原预条件器先按四个物理层窗口近似处理耦合，再用 64 个训练方向校正全局误差。FGMRES 用这些作用逐步逼近原方程解。CGS2 是对新 Krylov 向量做两遍经典 Gram–Schmidt 正交化，减少有限精度下与已有方向的混杂；它增加正交化工作，但不增加 rank64 或 restart300，也不改原 A。这里的 RR 是原方程残差范数除以原右端范数，越小表示越接近该离散方程的解，不等于连续物理误差。

**单位更正：** 原 CSV 的 `lambda_microns` 和 JSON 的 `wavelength_microns` 是历史字段名错误；原配置及中文报告使用 **nm**。新 [CSV](results.csv) 和 [JSON](results.json) 统一写 `wavelength_nm`，0.70/0.84 数值不变，**不是单位换算**。原四件材料私有保留，历史字节和哈希不改；本公开版不包含原始归档或私有恢复标识。

## 3. 能说明什么，不能说明什么

- 三个正常旧新配对核对了自身 A、相同 literal seed 及 preouter/rank64 证书；836 例保留自身 A/TrainingBank/生成器证据，不宣称逐个保存 seed 字节重放。
- 四个新运行都早于首次计划 checkpoint 299 结束；299/300/599/600 均未到达。因此没有同一迭代向量的直接对照，也不能据此证明 Arnoldi 正交性是唯一因果。
- 这是固定 p6、有限单元数和模态集合上的改善观察，不证明 h 无关、k 稳健、网格收敛、全尺寸性能或无限模态尾截断充分。λ0.70 的 120→180 cells 下新迭代 102→163 本身仍有增长。
- 新 root 状态保持 `ALGEBRAIC_PASS_PENDING_PHYSICS`；本次保存解审计不是新物理验证。**PML 暂停，未纳入本轮比较。**

## 5. 已检验但不继续扩大的方向

近截止端口富集曾用物理端口方向替换部分随机方向，仍保持总 rank64。该次正常完成 **1354 步**，原运行报告 RR 为 **2.080593e−11**；保存解另经独立原 A 审计为 **2.080755e−11**，与已验证的旧 random64 保存解相对差 **5.227515e−12**；单次监督耗时 **1356.747604 s**、RSS 峰 **3,112,349,696 bytes**。见 [Port 结果与历史证据哈希](results.json)。此尝试未支持改善，因此不继续搜索 χ、比例或 rank；这不是将 Port 算法普遍判为失败。旧 random64 的 770 是中断轨迹而非正常终态，不能与 1354 做严格的正常收敛速度比；后来 152 步的 CGS2 还改变了正交策略，不能把两者差异全部归因于 Port。

另一个已完成的物理敏感性检查将同一有限元网格上的端口从 836 扩至 1380，并同时把表面积分规则从 q28 改为 q40。已有 1380 `never` 解的独立原弱式残差为 **1.493453e−10**，MPC 约束误差为 0；其 192×192 固定采样的 R/T 为 **0.0986468343 / 0.8928475131**，材料吸收（体积 q32）为 **0.00850564534**。这些是该有限模型的后处理观察，不能把采样的 `1−R−T` 自动等同材料吸收，也不是对四个 CGS2 保存解重新做物理认证。

836→1380 比较中，完整散射 FE 系数的欧氏相对变化为 **2.160945e−7**（不是物理 L2/Hcurl 误差）；相同 192×192 采样的 R、T 绝对变化分别 **3.013426e−10、2.392603e−10**。然而模态数与积分规则同时改变，旧/新轨迹证据层级不同；这只能称有限模型敏感性，不能证明网格精度、无限尾截断充分性，或把变化归给某一单独因素。详见 [有限模型比较摘要（完整证据私有）](results.json)。
