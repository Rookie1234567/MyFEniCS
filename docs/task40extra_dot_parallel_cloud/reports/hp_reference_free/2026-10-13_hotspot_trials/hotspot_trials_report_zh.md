# 第三阶段热点 P 与 Hx 实际试验结果

截至本次快照，两项候选的离散求解与固定测试空间测量均通过各自检查，但都没有被接受为新主状态，继续保留 S3。P 在 y/z 改善的同时使 x 的受限残差平方增加约 0.615%；Hx 的三个方向均变差。现有 0.7 nm 研究模型仍未建立空间收敛，研究继续。

## 试验改变了什么

从相同 S3 场出发，P 将顶层中央周期配对 K1,0,2 与 K1,1,2 从 p5 升为 p6，以增加局部表示能力。Hx 则沿 x 分割该热点，并执行兼容闭包：实际影响中央列的六个父单元，子单元继承原阶数。两次都真正重新求解 PDE，使用 S3 的非零传递初值及各自新建的稀疏因子；没有复用旧因子，也没有零初值配对试验证明加速。

| 实际量 | P 热点升阶 | Hx 热点分割 |
|---|---:|---:|
| 单元数 | 18 | 24 |
| 阶数分布 | 6p4 + 10p5 + 2p6 | 8p4 + 16p5 |
| 独立 FE 未知量 | 6346 | 7792 |
| 相对 S3 新增 FE | +502 | +1948 |
| R 总反射率 | 0.9999124867381 | 0.999933690153 |
| T 总透射率 | 7.381050863513e-05 | 3.635568278136e-05 |
| A 体积吸收率 | 1.370275317578e-05 | 2.995416425877e-05 |
| 完整活跃方程真实相对残差 | 8.138733034e-14 | 2.525370856e-13 |
| PDE 监督 wall 秒 | 26.211394382 | 28.481811331 |
| PDE 采样进程树 RSS 峰值 B | 1006817280 | 1001029632 |

R/T 来自 DtN 模态幅度，A 为体积吸收；80 个固定辅助端口不计入独立 FE。完整活跃残差来自原求解记录并经保存证据审查，另外独立复算了保存 CSR 的凝聚残差；没有重新装配全部 FE 方程。小代数残差与能量平衡说明当前离散方程求解可靠，不能证明空间离散已经准确。两个候选不是等 DOF 比较。

## 在完全相同的冻结测试空间中比较

P 的 x 方向 trace 同样增加约 9.45%，因此 y/z 改善没有消除方向冲突。Hx 的三个方向 bubble 和 trace 都增加。本轮采用保守实验判据，在固定方向仍有恶化时不替换 S3；这不是必须单调下降的数学定理，也不能据此断言这些候选真实误差一定更大。原始测量程序仅给出描述性对比，并未自动决定接受。

q15/q19 完整作用对照的固定尺度相对差约 4.94e−14 至 1.36e−13；这支持已测积分一致性，不能排除共同模式误差。原 x 提取后 raw replay 的失败及不变的 1e−9 门保留，直接作用原 carrier 的成功控制没有改写该失败。
