# 108 单元 BAL_H：有界回收外层实测与因果证据汇总

记录时间：2026-10-14T18:02:10.522249+00:00。同一 0.7 nm 缩尺模型；本报告没有新物理解或 hp 收敛声明。

## 结果先说清楚

唯一试验已完成：setup 1 次 + 外层 199 次 BAL_H 应用，共 200 次。独立重放原保存 CSR 得相对残差 **0.0129352133872**，原 1e−9 门未过；原生算子现场相对残差 **0.0129352131011**，1e−11 门也未过。没有恢复为合格物理场，现有合格场仍为 96 单元。

同 6656 起点、同 A/M、p4 粗层与 H3 下，192 次外层应用处：旧 FGMRES32 为 **0.0200274043743**，新候选为 **0.0130219340412**，降低约 **34.98%**。这是有效改善，尚未修复平台。SciPy 使用 MGS，旧 PETSc 使用 CGS/no refinement，加上逐周期库调用等实现差异，不能把全部改善严格归于“只增加回收”一个选项。

- 每个完整周期固定 32 个新方向，最多保留 8 对经 AU=C 和正交性检查的方向；本次实际最高秩 7。
- SciPy 的实际新方向数为 m_call + max(8−rank,0)，所以 m_call 为 24、25、26、27、28、29、5；实际方向数为 32×6 + 7。没有把 SciPy 外循环次数当方向数。

## 验证与限制

- 7 个回收池全部通过：最坏 AU=C 相对缺陷约 7.09e−11，正交缺陷约 2.07e−15。400 次逻辑 p4 调用全部达到原返回残差门；其中 198 次使用一次原允许的修正，没有耗尽修正次数。
- 1130 条原外部资源样本与 51 次实际预分配门通过；零 swap，原监督器确认退出与清场。
- 独立 stdlib 流式计算原保存 Ax−b，重核 A/b/x 文件、payload、typed SHA 和有限性。相对残差与现场值差 4.18e−14。此独立外部复核仅重放保存 CSR；native 最终残差来自生产过程中独立原生算子的实际作用，不冒称另跑了第二次原生终核。
- 最终因两个原验收门未过，保留 CHILD_FAILED/FAIL。−3 是 wrapper 的合成状态，具体停止原因是 TOTAL_PC_CAP；没有说数值发散。完整场恢复、端口物理解验收没有启动，不能把未执行门称通过。
- 所有旧 geometry/checker/oracle MISMATCH 和失败都保留。

## 今日干预的因果结论

下表与下一方案以随附 JSON 的 source-backed causal_synthesis 为准；通过的范围均有限。

| 检查或干预 | 已有证据 | 不能据此声称 |
|---|---|---|
| 原 hp fine-exact 漏接；入口 self-test 尺度与 loader | 这些是已定位的真实接线问题；native fine exact 路径仍出现平台 | 修好了这些就已修复 108 平台 |
| 恢复恒等式 checker | i=Ht 的重构内残差会隐藏独立 raw 恢复缺陷；旧门 FAIL 保留 | checker 改进等于物理算子或外层平台已修复 |
| p4 exact 几何单项对照 | 该对照没有改善完整方向 | 所有舍入影响已被排除 |
| H6 算子/对角及原生/packed 动作 | 已测向量的一致性支持当前实现；有限谱探测不是全谱界 | 任意方向/所有状态均无 bug |
| 旧 132 成功入口复现 | 当前完整路径 200 步约 9.84e−7，过历史 1e−6；严格 1e−9 未过 | 当前程序普遍回归失败，或 132 已满足当前严格验收 |
| matched 108/144、仅中层 z 二分 | 两条 200 步观察诊断仍在百分比量级，原 identity FAIL 未取消 | 一次 z 二分已经解决，或已严格证明长宽比因果 |
| p4→p5 粗层单项 200 步 | 约降至 0.0102284，有改善仍不合格 | 粗层只差一阶就是唯一根因 |
| H3→H11 与充分 B 逆 | H11 不是精确逆；固定方向 B 解达 9.84e−7 后完整 PC 仍弱 | 正辅助 B 无法求解，或任何更好 smoother 都无用 |
| 两方向独立最优权重 | retained 最佳一步约 0.994579，与固定和约 0.994625 差很小 | 改两个系数便能治好平台 |
| 首 32 步正交性与真实残差 | Gram 约 1e−13、真残差/递推差很小 | 所有后续周期均无失正交 |
| restart128、此次 recycling | 两者均有有限改善，未达验收 | 单步弱作用必然导致 GMRES 失败，或此次已修复/已收敛 |

当前没有证据把 108 平台归于一个已经修复的致因 bug。证据支持粗空间对难方向的捕获与重启子空间保留都可能影响实际收敛，但主因尚未严格隔离。

## 下一项最小、可证伪的设计（未启动）

阶段决定：下面的固定细空间粗层消融能区分机制，但跨网格 P/Pᴴ 是明显较大的专项实现，目前不实施、不运行。优先只读检查更小路线：已有 108 困难残差的正确单元/方向归属，或现成同网格局部 z 向粗空间富集；若没有可靠低成本接口，明确记录需要下一阶段实现，不为继续而扩大开发。

固定当前已复现的 132 细空间、物理 A、H6、零初值及端口，只把其 p4 粗网格的中间材料层由 9 段合为 1 段，保留所有材料界面，形成 6×2×3 粗网格；与原同网格 p4 粗层比较。这样可以在细方程不变时测试粗层 z 分辨率的作用。

这不是现成参数切换：当前 BAL_H transfer 明确要求同一 mesh。需要先构造真正嵌套的跨网格 H(curl) 原始/对偶转移，核周期与端口、A_c=PᴴA_fP、粗凝聚恢复和实际符号资源。已有单场 warm transfer 不等价于可复用 P/Pᴴ，也不能用未过当前真残差门的 132 向量冒充合格 warm 场。实现与资源资格仍未知，任何一项不能合格就停止该路线；本报告不授权运行。

若只换粗层后由已知快收敛变成明显平台，将支持粗空间分辨率不足这一机制；若变化很小，则反驳其作为唯一解释。即使支持，也不把它当各向异性理论的普遍结论。先完成这些小接口/符号可行性检查，再决定是否值得做一个有界外层对照，不能先扩展网格扫描。
