## 结论

同一个初值继续 200 步后，A 原 BAL_H 的 native 真相对残差为 0.0006933641170938657，B 固定八方向补偿为 0.0006934679747113452。B 比 A 高 0.01497880%，原监督 wall 多 20.317362 秒。本固定方案没有显示新增收益；两臂均未通过 native 1e−11、saved 1e−9 或最终 native 物理恢复恒等式门限，没有合格的 108 单元物理场。

独立终态审查完成，资源、清场、相同初值及原记录的门限分类已核查；独立 saved CSR 重算有 8/9 项记录一致、1 项 MISMATCH，必须保留，不能称“全部复核通过”。单对实验没有重复试验或误差条，不能据此否定所有低秩/回收方法，也没有单独定位 BAL_H 停滞的唯一 bug。不得作 hp/连续收敛或生产资格声明。

## 比较什么，以及什么不算新收益

模型保留 23976 个 trace 自由度和全部 80 个端口，总计 24056 行。A 为原 M；B 为 C+(I−CA)M(I−AC)，C=U Yᴴ。通俗地说，B 用此前求解积累的八个固定方向先纠正一部分残差，再让原方法处理剩余部分，最后消去重复分量；收益需要抵偿低秩投影和额外算子作用。

实际实现为 a=Yᴴv，z=M(v−Ya)，再返回 z+U(a−YᴴA_native z)。经本次 native AU≈Y、YᴴY≈I 资格后复用 Y，每次 B outer 作用为 1 次原 M 加 1 次额外 native A。M 可能依赖输入，因此使用 right FGMRES，不作固定线性 PC 或谱性质结论。没有裁剪端口或修改 alpha。

两臂统一 restart32、原 CGS+refine_always、非零初值、最多 200 步及 hard 600 秒；实际 PETSc KSP view 已核对。八方向来自此前已付费的 64、128、…、512 步相邻增量，不选秩、不挑方向、不追加训练。两臂加载完全相同的 common_xinit_native，typed SHA256 为 `31ebf34e7e95549d9508d00235ddaecee28a1dea0d1814d0c183d507fa67b10c`；初始 native/saved 真相对残差分别为 0.0006937698325630256 / 0.0006937697999426029。

该 common x_init 与已付费 x512 的向量相对差仅 3.390347457215723e−15，初始下降属于旧训练结果的近似重构，不能记为 B 或新方法增益。真正比较是本报告的同 x0、同步数 B/A。
