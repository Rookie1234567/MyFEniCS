## 三、必须实现的机制

本轮研究的是“局部 PML＋累计源转移＋重构”，请明确它与旧方法的区别：

- 将计算域沿 z 划成若干物理层。
- 博客中的基本局部问题覆盖相邻两个物理层，并附加局部 PML。
- 求出局部辅助场后，通过平滑截断场的弱形式残量构造转移源。
- 下一局部问题的右端由原始激励与已转移的累计源组成。
- 按一致的正反向递推与重构规则生成全局场或修正向量。
- 用作 PC 时，当前全局残差是这一轮源转移要处理的输入。

请先写清本实现采用的局部方程、源转移、端点处理与重构公式，统一正负号，给出对应代码入口。

**不能仅将已有 `r ← r − Aδu` 的 multiplicative Schwarz 双扫改名为 PSTDDM。** 旧代码中的网格、映射、PML 和局部逆组件可以复用，但必须真正实现本次声明的源转移规则。

实现时特别注意：

1. Nédélec 自由度不是普通节点值。构造 βE 时，应按弱形式处理
   `curl(βE) = β curl(E) + grad(β) × E`，不能用“每个 edge DOF 乘一个 β 值”直接替代。
2. 必须正确处理局部／全局 DOF orientation、Floquet 相位、primal/dual 映射和重构连续性。
3. 凝聚后的 trace residual 不能未经 lifting 就当作体源 f。**本轮优先使用可承受的未凝聚小型 H(curl) 系统**；如果复用凝聚系统，必须先明确并验证 RHS lifting 与完整恢复。
4. 全局原始 A 保留真实材料、双 Floquet 和 Fourier-DtN。PML 用于局部辅助问题，明确人工切面、端点局部边界与材料延拓规则。
5. 不直接复用只对“无 PML、常材料”成立的旧张量缓存。新 PML 的 stretch、材料张量和积分形式必须有正确的缓存身份。

## 四、按以下顺序完成最小试验

### A. 一轮最小正确性检查

选择一个很小的平滑制造解或已有可信全局直接解，检查局部求解、截断弱残量、源转移和重构是否一致。

只做与新算法直接相关的必要检查，不重新展开全仓库审计或多轮测试矩阵。优先定位符号、映射、端点重复计源和重构错误。

### B. 固定一个真实三维小模型

优先复用你已有的、含明确非可分三维扰动的小型 0.7 nm 模型及材料资料，从可承受的 p2 开始。

在运行前冻结并记录：

- 几何、材料、波长、入射角和偏振；
- 网格及 p；
- Floquet 相位；
- 全部 DtN 模式及 quadrature；
- 原始 RHS、全局算子定义和场恢复方式。

建立同一离散系统的 global direct reference，保存必要的参考场与原始残差。若复用旧 reference，必须核对完整输入、源码和数组身份，不能只拿几个 R/T 数值当全场参考。

这里的 p2 小模型只承担算法与同离散求解资格，不宣称目标物理精度。

### C. 保持上述模型不变，只改变分区数

优先比较 N=2、4、8；若原网格不允许这些切分，选其中合法的分区数，并说明原因。

要求：

- 所有分界面落在合法网格面上。
- 不为凑 N=8 而悄悄重划全局网格。
- 固定 PML 的物理厚度、轮廓、局部网格规则和材料延拓规则。
- 固定局部求解精度、外层算法与因子保存策略。
- N=2 的两层局部问题可能已经覆盖全物理域，主要作为正确性锚点，不预期它一定节省内存；容量不允许时可跳过。
- 至少有两个合法分区点，才能讨论“增加分区数量”的趋势。

每个 N 的正式计算可以采用一个明确的流程：

1. 先做一次源转移双扫，得到初值 x0；
2. 记录 x0 的原始 true residual、对 reference 的场误差；
3. 若尚未满足最终门槛，以这个明确的初值继续外层 FGMRES，源转移作为 PC；
4. 最后比较完整解和全过程资源。

把“源转移初值＋FGMRES”写进配置，不在一个 `.dat` 中暗藏多个不同模型。**单次双扫未达到最终残差门槛，不构成禁止进入外层迭代的理由。**

### D. 有正结果且剩余预算足够时，再做一次 p4 对照

仅对选定分区数，成对完成小型 p4 direct reference 与候选求解。

本轮不启动 p6 或目标规模计算，不同时扩展新的 coarse space、神经网络或其他 PC 家族。

## 五、数值与物理判据

以下是本轮新 pilot 的判据，不回写或改变旧任务的历史资格：

- Direct reference 的原始 true residual ≤ 1e−10；若参考本身不合格，先处理参考问题，不能将后续差异归罪于 PSTDDM。
- 候选最终原始 true residual ≤ 1e−8。
- 物理域复数 E 对 reference 的相对 L² 误差 ≤ 1e−4。
- 记录复数 H；已有合格恢复方式时，采用相对场误差 ≤ 1e−3 的本轮比较门槛。
- 使用已有合格后处理，比较 R、T、通量吸收、体吸收及主要衍射级。总功率量按入射功率归一化后的绝对差 ≤ 1e−4，不用接近零的吸收值作为相对误差分母。
- 同时报告候选与 reference 的能量缺口。若某项后处理在该小模型上尚未资格化，明确标为 diagnostic／未资格，不据此宣称完整物理通过。

若使用 FE＋aux 表述，原始残差必须包含相应端口／辅助方程；若使用凝聚，必须恢复并检查原始系统，不能只用预条件残差或凝聚内部残差宣布成功。

同离散 solver 一致性通过，不等于网格收敛、DtN 截断收敛或目标尺度通过。

## 六、本轮预算与停止条件

这是本轮新试验的独立预算，不继承已经结束的 Task44 时间窗口：

- MPI1、单线程，一次一个正式 PDE。
- 正常计划约 6 次正式运行；条件允许的 p4 对照增加 2 次；最多再允许 2 次针对性重试，合计不超过 10 次。
- 累计数值运行预算 6 小时，包括 JIT、setup、求解、恢复、输出、失败运行和重试。
- 单次完整计算上限 30 分钟；预算达到后保存状态和证据，给出阶段结论，不自动延长。
- 进程树 RSS 上限取 `8,000,000,000 B` 与现场安全可用预算中的较小值；保留至少 1 GiB 系统 available 和独立 512 MiB 阶段余量，服从现场更严格限制。
- 任务 swap=0。JIT 编译器、MPI 子进程、局部 factor、恢复和输出均计入监测。受控终止完整进程组，不能依赖 OOM。
- 外层 FGMRES 固定 restart=30、最多 100 步，记录原始 true residual 历程。明确停滞时可以提前停止并给出证据。

允许自行修复明确的接口、编号、符号、编译或局部内存生命周期问题，然后在预算内继续。

低分区数因局部问题过大而触发资源停止时，允许转到更大的合法分区数重试；不得通过改变全局物理或网格冒充同一对照。

不要通过增加真实材料损耗、删模式、放宽误差门槛，或不断扫描 PML 参数来制造通过。所有合法候选在预算内都未通过时，准确报告这一具体实现的失败或阻塞位置，不扩大为整个方法家族不可能。

## 七、内存与时间必须怎样统计

每个 N 至少记录：

- 全局自由度、最大局部自由度、PML 自由度；
- 局部矩阵与因子的数量、同时驻留数量；
- 因子是缓存、释放重建还是读盘；
- 局部装配、分解、solve 次数；
- 首次 setup、首次双扫、后续 PC apply、外层迭代、恢复／输出时间；
- 全过程 process-tree RSS 峰值、swap、总 wall time；
- cold／warm cache 状态和实际复用内容。

不要把单个局部 factor 的内存当成全过程峰值，也不要把全部缓存因子忽略掉。比较分区数时使用一致的缓存策略。

不能只报告“迭代次数更少”；主要结果应是精度、完整时间和实际峰值内存之间的关系。
