# PSTDDM pilot V2：独立保存数组复核

日期：2026-11-11 UTC。结论：**PASS_WITH_QUALIFICATIONS：小型同离散求解通过，内存与全过程时间收益未出现；不批准扩大运行或提升普通默认。**

这里的“同离散”是指：用新的源转移方法，是否得到与同一有限元矩阵直接求解相同的复电磁场。它不回答网格足够细、端口截断足够多或真实物理结果足够准确的问题。本次没有重新装配、求解 PDE 或分解矩阵，只读取四个已冻结运行目录，独立做稀疏矩阵作用、约束重建、场误差积分和资源核验。

## 1. 直接回答

1. **实现了真正的累计源转移。** 新路径含独立双向源递推、弱截断交换项、局部 PML、非零原源截断和连续场投影，不是旧 Schwarz 残差更新改名。原生检查和制造源检查支持本次实现，但不是对任意材料和边界的收敛定理。
2. **N=4 一次双扫不够，FGMRES 后通过。** 真实 0.7 nm 小模型初扫真残差为 0.11157；18 步后降至 5.7441e-9，总场及散射场 E/H 均与直接参考一致到本任务要求以内。
3. **增加分区没有降低本轮实测内存或时间。** N=4 比 N=2 多用约 42.5% 峰值 RSS、45.1% 全过程时间；相比直接参考则约为 2.14 倍内存、2.87 倍时间。
4. **下一步应先修改成本结构，再谈扩大。** 本轮到此停止数值扩展。N=8 不适配原四层网格；p4 的既定 direct 计划余量约 36.765 GiB，不能进入 2 GiB 门，不实际运行。不能把这解释成 PSTDDM 方法族必然失败，也不能据此承诺目标规模可行。

## 2. 模型、身份和复核范围

四案数值 source SHA 均为 `bd0d4daed6da301eaca26b2fdac76a59a834be8a`。模型为 0.7 nm、固定 Si 光学常数、有限 x/y 矩形块、120 个 hexa cells、p2、双 Floquet 和完整 836 个 DtN 辅助模式；不是 y 不变模型，也不代表任意复杂三维几何已验证。原 FE 有 3570 个系数，450 个周期 slave，3120 个独立 FE 未知，加端口后 3956 阶。

独立 checker 从原 MPC 的 slave/master/offset/coefficient 数组重建 T，与保存 T 完全相同。四案 A/C/D/T、质量矩阵、curl Gram 和完整矩阵的规范化数组身份一致；三案真实物理 RHS 完全一致。制造源的 RHS 单独保存，投影一致性相对误差 1.51e-16，没有拿原物理 RHS 冒充制造 RHS。

从 raw A/C/D 重新构造约束后的块算子，核对原 FE 投影方程、辅助端口方程、原 MPC 约束，以及解析背景的质量/curl 交叉项。原始完整方程真残差与保存 full 矩阵残差均通过；所有重建场的 MPC 最大绝对误差为 0。

独立复算代码：[`review_saved.py`](../../../benchmarks/pstddm_partition_pilot/review_saved.py)。机器可读证据：[`saved_arrays_review_v2.json`](outcomes/independent_review/saved_arrays_review_v2.json)。原始目录位于 `benchmarks/artifacts/pstddm_partition_pilot/`，没有修改。

## 4. 为什么本小例没有省资源

N=2 的一个 pair 覆盖整个物理域，并保留两个原 DtN 端点，没有人工 PML。这是端点计源和映射正确性的退化对照，不是可扩展局部预条件器成功的证据。独立比较其映射后算子与原 A-CD，Frobenius 相对差为 1.63e-16。

N=4 的固定 10 nm PML 比部分物理层厚。中间 pair 因加入两侧 PML 达到 4560 个独立局部系数、4080 个 PEC-free 系数，反而大于全局独立 FE 的 3120 个。全程还缓存三个局部因子和一个全局质量因子，不能声称完全取消全局分解。

| 项目 | Direct | N=2 | N=4 |
|---|---:|---:|---:|
| Maxwell / 局部因子数 | 1 | 1 | 3 |
| 最大局部 free rows | 不适用 | 3120 | 4080 |
| 全局质量因子数 | 0 | 1 | 1 |
| 同时保留因子的 L+U nnz 总数 | 5,424,251 | 5,418,377 | 12,025,529 |
| 实际局部 solve 总次数 | 不适用 | 2 | 114 |
| 局部装配 / s | 不适用 | 24.716 | 48.037 |
| 局部 factor / s | 不适用 | 0.500 | 1.096 |
| 第一次双扫 / s | 不适用 | 0.0224 | 0.0448 |
| FGMRES 全程 / s | 不适用 | 0.0010 | 0.8956 |

nnz 不是 RSS，不能互相替换。四案使用独立的新 JIT 输出目录，完整时间含首次装配/JIT、参考读取、局部建立、恢复和输出；后续 PC apply 重用当前案局部因子。本轮没有另跑 warm-cache benchmark，不能由不到一秒的外迭代时间替代 82.3 秒全过程。

## 5. 物理资格与负结果

真实直接参考的诊断值为 R=0.11328667、T=0.88179909、A_flux=0.00491424、A_volume=0.00961703，能量缺口约 0.00470279，即入射功率的 0.4703%。N=4 与参考的这些诊断差异在约 1e-12 内，只说明双方解了同一个离散问题，**不能证明物理能量误差消失或模型已收敛**。

制造源案的功率归一化差量最大约 1.02885e-4，略高于 1e-4；原记录保留该负诊断。该案是人工 FE/aux 载荷，不是物理入射试验，不能把其单位入射功率归一化当作真实散射物理资格，也不能删除此项以包装“全指标通过”。

没有网格、阶次或 DtN 模式收敛研究。PML 固定参数没有扫描。保存的 DG H 插值并未作为 H 误差分母；本次 H 误差由原 FE curl Gram 和同一解析背景独立重算。任意几何、强散射、高阶、大尺度及目标 2 TB / 48 h 能力均未验证。

## 6. 资源和证据完整性

四个正式 case 共 249.892 秒；每案均低于 1800 秒，没有继续启动 p4。全部资源采样与阶段前瞻门通过，零 swap、swap 计数不变、无遗留进程；最大输出约 145.63 MB，包含 JIT 和监督记录，在 256 MiB 内。每案全部 artifact manifest 条目均已重新哈希，并核对最终输出总量。

本次独立 checker 最终运行约 2.62 秒、峰值 RSS 225,366,016 B（约 214.93 MiB），以单线程逐案读取，没有复用原生装配或求解器。质量分层、局部 weak-product 和 local phase-map 数值来自原运行记录，另有静态代码审查；它们没有在本次 checker 中重新装配，不能与独立原方程复算混称。

资源保护仍是 100 ms 采样和前瞻估计，不是经验证的内核硬配额。源码提交和全部原运行目录应保留，失败、未运行和诊断不合格项不得改写。

## 7. 后续判断

接受本轮研究结果和受限实现，保留在独占研究分支；不提升 production default，不批准 PR/merge。若以后另立下一阶段，应先研究局部因子驻留/重建策略和 PML 开销相对物理子域的比例，并继续保留同系统参考场及全部成本，而不是直接提高 p 或规模。本轮证据只能支持“源转移可作为这个小模型的有效求解操作”，不能支持“已找到节省内存的可扩展路线”。
