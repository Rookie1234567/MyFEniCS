# 用户续作：p6 凝聚直接解收敛与同网格迭代比较

本文件记录 p2 波长试验收口后用户的新明确要求：先用 p6、h10/h7.5 和静态凝聚直接法验证网格，再在同一网格上运行迭代法，检验能否省内存。基线为 `94d137788bd0c828cbb25d539112c293e316b44f`。不改写旧 task、response、六场结果或旧资源停止分类。

静态凝聚先在各单元内消去内部未知量，只对单元之间的界面和端口未知量建立全局直接分解，随后恢复全部内部场。它不降低 p，不删除原方程；验收必须回到完整原系统。迭代比较仍是本任务的 PSTDDM 源转移方法，不能静默换成其他预条件器，也不能把凝聚后的界面残差未经正确提升直接当作体源。

## 顺序与物理

先完成13.5 nm；5 nm/0.7 nm暂缓。保持上一轮50×50×140 nm单胞、17×20×120 nm居中有限宽Si块、10 nm Si基底、phi90/掠角1°/S、双Floquet和上下DtN。没有新增缺口、PML全局吸收或材料修改。冻结本波长同一材料数据、612模式有序清单、积分与相位；p2功率诊断失衡不能被改成合格，也不能假定提高p就自动消失。

计划仅两场独立直接解及一场条件迭代：p6h10 direct → p6h7.5 direct → 收敛且物理资格通过后，在同一h7.5网格运行一次N4 PSTDDM/FGMRES。直接解只作为比较基准，不作为迭代初值；采用既有明确的源转移初扫后FGMRES流程，报告初扫与最终原残差。未过收敛或物理门则保存真实差异，不自动加密或扫描参数。

材料面固定为x=[0,16.5,33.5,50]、y=[0,15,35,50]、z=[-10,0,120,130] nm，各区间以ceil(length/h)等分。h表示各坐标方向的最大单元边长，不是三维直径。以下仅为构建前派生值，正式mesh、材料tag、DoF及MPC必须实际读回：

所有内变量、非零内部/端口RHS、左右耦合与恢复均保留。直接法优先复用已有assembly-time condensation与准确MUMPS路径，禁止先建立完整p6全局矩阵再声称节约了该对象。

## 比较与证据

两张网格在共同物理子分区/积分点比较复数总场和散射E/H及curl，不拟合相位，不在不同几何或不同模式之间套同离散门。报告显著复模式、全部模式、R/T、通量/体吸收与能量闭合。数值残差、物理资格、网格变化三类结论分别报告；两张网格的一致性只是有限网格证据，不证明连续极限精度。

直接解完整原残差沿用≤1e-10；迭代沿用≤1e-8及同离散E/H误差≤1e-4/1e-3，合格功率差≤1e-4。首场计算前冻结本轮有限网格比较门：以h7.5为参考，共同子分区上总场和散射场E/H的相对L2差均≤1%，显著复模式差≤1%，R/T/体吸收的入射功率归一化绝对差各≤1e-3，两场各自能量闭合绝对误差≤1e-5。显著模式定义为任一网格该通道功率≥1e-6入射功率；全部模式仍完整保存并报告，不以筛选删除结果。模式比较不拟合相位；接近零的分母明确列出并保留绝对差。后处理必须使用实际总场与原端口gauge、入射功率、复材料损耗，不能依赖既有“有损材料自动放行”的布尔状态。若物理或网格门未过，不启动条件迭代、不称收敛。旧diagnostic输出不能作为通过物理门的唯一依据。

比较包含局部生成/消元、全局装配、因子、所有常驻缓存、lifting/重构质量因子、Krylov、恢复、输出与checker的完整成本，冷/热JIT分列。direct因子不得在迭代场中隐藏常驻。任何辅助问题仍持有全局因子均明确列出，不能只报KSP或单个因子内存。
