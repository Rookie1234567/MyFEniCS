# 缩尺模型 h/p 自适应：扩展目标直接重比结果

更新：2026-10-21T03:10:45Z。结果位于 dot 云电脑；不声称已推送到 GitHub。

## 结论

**两个原始核心上的直接重比均通过独立审计。** 保留扩展补丁产生的非零界面迹后，误差从小到大的次序仍为 **hy、p、hz、hx**。不过，按“局部新增自由度带来的平方误差下降”衡量，**p 比 hy 更划算，约为 1.64 倍**。这两个结论对应不同目标，不能合并成一个无条件的全局选择。

本次没有重做 Maxwell 求解，没有启动 270 单元或混合 p 全局求解；也没有证明全局 h/p 收敛。原先的充分稳定性界仍未通过，直接重比只确认这两个已测试扩展目标上的排序一致。

## 模型与比较对象

当前是 216 单元（3×8×9）、p6 的缩尺周期模型。x/y 周期均为 2.5925925925925926 nm；z ∈ [−0.5185185185185185, 6.7407407407407405] nm，跨度约 7.25925925925926 nm。波长 0.7 nm，方位角 90°、掠入射角 1°、s 偏振。这不是完整 50×25×140 nm 模型，也不是对完整模型 2 TB / 48 小时目标的验收。

已接受全局源的真实原生相对残差为 9.863889341955086e−7，符合其 1e−6 代数求解合同（累计 1085 步，其中本次源求解新增 109 步）。这是线性方程残差，不是空间离散误差或全局自适应收敛证明。

两核心共有 x ∈ [0.8555555555555555, 1.737037037037037]、z ∈ [0, 1.2444444444444445]：
- Core24：y ∈ [0.3888888888888889, 0.7777777777777778]；向 y+ 扩展到邻居 37。
- Core117：y ∈ [1.8148148148148147, 2.2037037037037037]；物理核心在上方，向 y− 扩展到邻居 94。空间排序材料角色分别为 [1,3]、[3,1]。

比较的目标是真实局部 Maxwell 修正，而非原 p6 场的投影。扩展补丁目标仅限制回**不变的原核心**，不是整个核心＋邻居扩展补丁的最优逼近；界面的 420 个完整行、364 个自由非零值全部保留。候选仍是原核心 H0(curl) 空间，目标是带非零迹的环境 H(curl) 场。

每个核心使用同一目标比较 base-p6、p7 诊断、hx/hy/hz-p6 五个候选，分别用 q15/q17 两种积分规则，共 20 个拟合。正图范数的平方定义为 ‖E‖² + ‖curl E‖²/k0²，k0 = 8.975979010256552，不带材料权重。

## 执行资格与全局代价不能混淆

- p 的公平前景是 e6/f6/c7 单元内部泡函数富集：每个选中单元 +306，两个单元 +612，现有全局迹 44,496 加端口 168、共 44,664 个保留坐标不变；不能只拿统一全局 p7 的巨大成本作为 p 的代价。
- 这条混合 p 路线尚未具备生产执行资格：仍须资格化真实基函数、离散正合序列、嵌套、异阶凝聚、恢复、真实算子/原生残差及传递。保留 p6/p5 BAL_H 只能作为待独立验证的代理预条件器；不能宣称旧粗层因子已可直接复用。
- h 的局部 +510 也不是全局张量闭包成本。单次 hx/hy/hz 切割分别预测 288/+47,232、243/+17,712、240/+15,552（单元数/独立 DOF 增量）。两个 y 切割预测 270 单元、+35,424 DOF；相同 x/z 闭包不可双重计数。
- 上述全局代价仅为计数预测，闭包实际增益与执行可行性未测量。两条路线都不得仅凭这些局部结果宣称全局性价比或收敛；也不能因为 p 尚未实现就自动选 h。
