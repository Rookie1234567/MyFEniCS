失败发生在 degree160 基函数计算前的单位权重和检查。历史异常文本声称 default 与 public Gauss 字节不同，但保存的两组节点和权重逐字节相等；真正未满足的是权重和误差超过 32ε。原始错误日志保持不变，此处明确纠正解释，不把它写成求积规则字节不一致。

机制比较允许极小舍入差异；两条路径的稀疏支持行并不完全相同，不能声称稀疏结构逐字节一致。完整原始与掩码后向量均按原定双边尺度阈值比较。完整六组误差、支持行差异和源码身份见[紧凑结果](records/chunked_surface_attempt1_v1/compact.json)。
