## 已解决问题

| 问题 | 原因 | 处理 |
|---|---|---|
| worktree长路径失败 | Windows Git long paths关闭 | 仓库本地设置 `core.longpaths=true` |
| 容器 `ruff: not found` | benchmark镜像未安装Ruff | 使用宿主Ruff 0.12.0 |
| 2D DtN + mpc_official被拒绝 | 2D nonlocal DtN只支持manual backend | 按能力边界切换manual |
| Task027 image缺少gmsh | HPDDM研究镜像未带2D网格依赖 | 2D smoke使用既有complex+gmsh镜像 |
| h2 clean RSS略高于Task027 | 本轮不复用basis/coarse cache | 峰值13.080 GB仍通过14 GB gate |
