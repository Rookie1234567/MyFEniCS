## 2. V45新增信息及其不能证明的结论

### 2.1 完整矩与远距离信息确实实现，选出的神经校正仍为零

有限模型是64hex、p6、q15、三tag，45000 native行／42624独立系数／2376 slave，**原A不含完整DtN**。DtN是把外部辐射与内部场连起来的边界算子；缺它的有限代数试验不能替代完整入射／散射问题。模型完整输出各实体6／60／450个复系数，分层让远处残差内容可以到达本地，不再强制把450个复数压进32个实数的唯一出口；代价是1817040实参数及大方阵乘法。

LIN-H把激活设为identity，是同信息实线性控制；NN-L只使用最细桶内容；NN-H使用全部层和根汇总。三者均128次真实FP64 Adam、batch2、CPU1更新，初始参数hash相同。9项FD最大3.01079069292e-9，小于1e-5；固定归一化γ的远内容见证约为LIN-H 0.00923697、NN-H 0.00921319、NN-L 0，排除了仅由归一化标量产生的伪远程信号。原s/Ad一致性最差约5.2143e-16。这些证明接线和信息通路，不证明网络学得了可消除误差的逆。
