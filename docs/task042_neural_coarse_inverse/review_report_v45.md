### 6.3 P2：强非神经控制与唯一神经候选

以下控制均实际执行，同一实体排序／分块／原字节；不得仅和未压缩RAW比较：

| 路线 | 要测什么、为什么需要 |
|---|---|
| RAW | 原complex128精确存储／直接消费；计实际bank，不加虚构缓冲 |
| BYTE | 原字节及固定byte-shuffle，各用现有zstd的level3／19；这是事先固定的四个传统控制，不再扫描level |
| XOR | 前值预测，以及固定表规模2^12的FCM／DFCM整数上下文预测控制；异或结果＋同一无损后编码，预测器／选择位／表全部收费。独立实现并测可逆性，不宣称复现论文性能 |
| LIN | 与NN相同因果特征、无隐藏层的实仿射预测，预测复系数实虚；同一异或和后编码 |
| NN | 唯一两层width32／tanh／FP64共享MLP，两个实输出预测复系数，参数≤10000；同一异或和后编码 |

共同后编码用现有zstd level3、单线程；不得安装／升级环境或把外部库性能当本轮测量。软件版本／二进制hash冻结。若不可用，可在第一次读取科学数组前一次性冻结标准库zlib level6作为所有相关路线共同后编码，并明确控制范围减少；不能看科学结果后换后端。BYTE的level19若因固定资源预算未完成，记NOT_RUN，不删掉它并宣称已超过最佳传统。

NN与LIN用相同、**解码时已知**的特征：同实体前4个已解码复系数的8个实分量，缺项为0；实体类型、方向及moment位置等有限静态特征。禁止当前／未来真系数、完整向量范数、未存下的尺度或全量17特征矩阵作为免费输入。每个实体首个复系数作为raw anchor原样存下并计费，不作为预测训练位置；前4项全为0时也使用显式raw fallback。其他位置允许因果尺度`max(1e-30,abs(已解码前4项))`，两路相同并明确复数abs定义；训练／验证和实际codec使用同一规则。静态映射若不能由已有consumer取得，额外字节计费。冻结具体特征维数、排序、归一化与初始化seed后再训练，不增加跨样本记忆表。

在训练前先用已经完成的正确传统控制和codec不可省的workspace／模型／索引下界检验：即使NN剩余payload为0，若也不可能把本有限trace bank对象降到传统的80%，则记`NO_COMPONENT_MEMORY_OPPORTUNITY`，不盲训，直接完成传统消费及P4；这是可复算的容量数值门，不是等待外部条件。不能用经验估计的“熵下界”代替严格字节下界。否则连续训练，两模型各**256次实际Adam更新**，lr=1e-3，batch=4096个实体内系数位置，从train16流式、固定循环采样，CPU1／math1／Torch1／DataLoader0。损失是因果尺度归一的复预测平方误差；checkpoint0／64／128／256。先做小batch非零VJP和3方向×3步长FD，操作尺度门1e-6；验证原始训练参数确实改变。梯度检查不涉及原A。模型不是原方程近似，不把训练loss当残差或压缩资格。

**checkpoint只能按validation4的实际完整码流字节总数选择，平局取较早一步；不能仅看MSE。** LIN同规则。包括权重／索引／header／raw fallback，不能只统计异或payload。zero输出／未更新模型可作step0控制，但若选0或与传统等效，真实训练仍收费，不写神经部署收益。只选一次模型，不根据heldout或迁移诊断重新训练、换seed／lr／宽度。

编码和解码都调用同一冻结NumPy FP64推理内核／权重，不以Torch编码、另一个运算顺序解码后假设预测位相同。核心逆变换是`uint64(original) XOR uint64(prediction)`再与同一prediction异或；**不得以浮点相减／相加冒称逐位无损**。强制坏hash、截断、端序、signed zero、次正规数及非有限特殊位模式测试；不能支持的数值块按显式raw fallback保存，selector／fallback费用如实计入。不同平台推理的可重复性本轮未证明，必须拒绝未绑定ABI，不能推广跨平台解码资格。

### 6.5 P4：把局部结果换算成目标机会，失败也完成分析
