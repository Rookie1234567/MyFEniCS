## 4. 为什么只值得再做一次在线资格试验

单步校正把一个预先计算的方向按固定系数加到解上；GMRES则在连续产生的方向中选择使真实线性系统残差下降的组合。**一次单位系数校正放大，不能推出该固定预条件器在GMRES中必失败。** 这不是以scalar-tau再调一个固定方向，而是检验可对任意新残差执行的全空间算子。固定/非固定迭代与残差最小化的区别可参阅[Netlib Templates](https://www.netlib.org/templates/templates.html)；右预条件的通用定义见[PETSc GMRES文档](https://petsc.org/release/manualpages/KSP/KSPGMRES/)，本仓库实际复用SciPy实现，不因此切换软件栈。

设A是保留完整40端口闭合后的原trace作用，B_J是J主块逆嵌回全域，L_O是其余六个主块逆的非重叠直和。真正在线的完整输入算子为：

```math
\begin{aligned}
q &= B_Jr,\\
v &= L_O(r-Aq),\\
B_{\mathrm{full}}r &= q+v-B_JAv\\
&= \left[B_J+(I-B_JA)L_O(I-AB_J)\right]r.
\end{aligned}
```

每次PC需要J两解、六外块各一解和两次A传播；外层每个Arnoldi步再支付一次A。这里“任意RHS”指18144维trace空间中的任意输入，不能据此声称已完成任意完整FE载荷的测试资格；本轮正式前向仍只有一个冻结物理RHS。V34从缓存省掉的外块成本必须恢复，不能拿20秒诊断冒充部署费用。令D_O为六个外主块的块对角矩阵，按J/O排列，有纸面恒等式：

```math
B_{\mathrm{full}}=
\begin{bmatrix}I&-A_{JJ}^{-1}A_{JO}\\0&I\end{bmatrix}
\begin{bmatrix}A_{JJ}^{-1}&0\\0&D_O^{-1}\end{bmatrix}
\begin{bmatrix}I&0\\-A_{OJ}A_{JJ}^{-1}&I\end{bmatrix}.
```

在各主块可逆的前提下，它具有全域输入/输出秩；旧B_ret只经J输入、rank≤3888的反对理由不适用于它。它仍然用D_O替代真正的外域Schur耦合，**没有解决长程传播的保证**。例如纸面2×2矩阵A=[1,2;3,1]给出B_full=[7,−2;−3,1]；对r=[0,1]单位步残差比为6，而AB_full在该方向的特征值为−5，GMRES能选不同系数组合消除它。这个代数反例只否定“单位步放大⇒GMRES必败”的推论，不预言本Maxwell系统收敛。

**本次值得继续的唯一原因是补上这个仍未测试的关键判别，价值是完整零初值求解或可信的在线负结果。** 不是继续搜索局部方向、再次制作dot身份表或维持一条无界探索路线。若§5进展门失败，结束当前固定七/八块族的追加数值预算。

### 6.3 神经网络的可验证机会和停止线

当前没有20%收益证据。若候选只能在固定V25–V32列空间调系数，已有精确最小二乘上限，继续训练没有增加可消除残差的自由度；若网络压缩局部逆，它可能省存储/每次solve，但不会自动解决外域全局耦合。两者必须分别评价。
