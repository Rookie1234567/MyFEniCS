## 2. 独立发现：下一步必须回答的三个问题

### 2.1 优化目标与停止条件没有共同保证完整误差

R0的η／ρ约6368..17795，这是这些已保存误差方向的观测比值，**不是全矩阵条件数估计或误差上界**。`fixed_cleanup()`在原残差达到1e-6时正常提前停止；R0还有37–41步未用，NN通常只剩8–14步。V43执行符合原合同，不能把它写成实现bug，也不能由这次终态断言128步以内必然达不到η门。

原残差损失对“场误差很大、乘A以后却很小”的方向不敏感。NN的validation中位数4.35990576→1.02735263主要证明比自己的坏初值好；零修正的ρ恰为1。缓变heldout上NN初始ρ约0.57..0.61，却比R0多迭代，说明一次降低残差不等于清除难误差。V44必须直接检验这种误差，而非再用自身起点下降授继续研究资格。

### 2.2 输出覆盖全部行，不等于具有全部误差表示能力

[`NeighborhoodCorrector`](../../src/solvers/neighborhood_residual_models.py)每类节点最终是一个线性decoder：NN用32个实隐藏量输出6／60／450个复矩。固定权重后，每个face或cell的输出只处于至多32实维的子空间；原方程对角尺度与方向桥不会增大该维数。按224 edge、208 face、64 cell计，整个NN输出范围维数上界为11392实维，完整独立系数空间则有85248实维。这个**结构推导不是实际秩测量，也不是加上传统清理后的误差下界**。

复线性控制的隐藏宽32指32复数，输出范围上界为10048复维／20096实维。它与NN参数总数接近，但latent维数和复线性约束不同。因此V43比较可以报告资源受限候选胜负，不能将差别唯一归因于tanh非线性。V44补一个与NN实虚通道、宽度、参数量完全一致的实线性控制；保留复线性控制以免漏掉更好的非神经路线。NN复相位缺陷1.24..1.70也不能充当非线性有用的证据。

不再先让同一局部网络近似任意完整逆，再期望传统清理免费补齐。V44让它学习固定64步之后的剩余误差；这些误差是否更可压缩、能否由两跳局部信息预测，均是待检验假设。失败后用完整误差分组和冻结decoder范围分析区分表示限制与训练限制，不能仅写“loss下降但没有收益”。

### 4.1 固定共同前段与新数据；不延长128步

为一个右端r，先从零做同一右对角GMRES最多64个Arnoldi步、restart32，取得z64及显式s=r−Az64。模型只输入s和已有局部实体身份，输出δ；之后从z64+δ继续**剩余的128−实际前段步数**。只调用一次模型，不做每次迭代神经PC、在线重训或scalar-tau搜索。R0令δ=0，其他规则完全相同。默认前段恰为两个完整restart，不能无端清空未到边界的Krylov状态来惩罚R0。

### 4.2 四个小模型、一个传统基线，分清学习收益来源

仍为两轮消息、宽32、CPU FP64、每模型≤100000实参数；相同图／归一化／右对角decoder，不加几何扫描、长程层、可训练DoF embedding或global P/Q。所有模型decoder初始精确零，encoder／message采用一个预登记seed的原规则；同结构NN两臂初始字节完全相同。零decoder的第一次反传只有decoder变化是链式法则的正常结果，不能因此判hidden梯度bug；后续必须记录各组真实变化。

令q_r=norm(s−Aδ)/norm(s)，q_e=norm(δ−d)/norm(d)，均使用完整原独立空间（原残差保留完整native行）。零修正两个非零量均为1。近零规则训练前冻结；精确零输入须精确零输出，分母为零时单独保存绝对误差，不删难样本，不用任意大floor掩盖误差。

| RL-E | NN-E同样70144实参数、实虚通道、全部层形状，只将tanh换成identity；同混合loss；隔离非线性本身的作用 |
| CL-E | V43复线性架构、74240实参数，零decoder、同混合loss；保留更大复latent表示的非神经竞争者 |

RL-E是对实虚向量的实线性映射，不自动满足复相位等变；CL-E必须通过复线性门。RL-E参数优化虽非凸，部署的输入输出映射仍线性，不记作神经非线性收益。NN-E优于NN-R只说明新的训练目标有用，必须同时胜过最佳合格R0／RL-E／CL-E才有神经增量证据。

四模型各最多128次Adam、batch2、lr1e-3及V43默认矩参数，checkpoint固定0/16/32/64/128；同一16样本循环，不扫描optimizer／seed／更新数。NN-R按validation median q_r选择；三个E臂按median q_e选择，平局依次比较max q_e、median q_r、较早step；所有q_r均保存，不隐瞒为减系数误差而放大残差。heldout绝不用于选择。固定完成至128或真实非有限／资源／预算门；不以相对坏初值下降为成功，不在一次更新后交回。

混合loss新增的系数梯度必须实际接进参数。沿用可信原A/Aᴴ链，最小重验新的完整loss／JVP／VJP、batch1/2和近零规则。3方向×3步长，至少相邻两档全向量FD≤1e-5，VJP运算尺度≤1e-10；包含message-only非零见证。可使用预登记的非零诊断权重核验链，再对候选执行零decoder初始化；不能用零hidden导数“通过”新loss。旧B12port链hash不变时复用，不再做端口梯度、MPI和恢复演示。

### 4.3 一次冻结终测；共同前段必须公平收费

四份模型与选择规则冻结后，8个新heldout分别比较五路线；完整保存z64、s、δ、最终z与显式原残差。执行器不读e；求解队列退出后独立checker核对40个唯一sample／route、split／权重／source／RHS身份、完整η和ρ、slave及覆盖；不足项明确NOT_RUN。

有限资格要求每条路线全部8个RHS：ρ≤1e-6、η≤1e-4、完整覆盖及约束通过。记录局部4个与缓变4个、trace与内部系数的误差，不能挑更有利的子组发布。学习修正是在共同传统迭代后的**warm correction**；只有R0从头到尾纯zero-start传统求解，不能声称模型独立zero-trace求解通过。

前段可在研究比较中只实际执行一次并保存给五路线读取，降低实验重复；**每条路线的独立部署费用都必须包含这段前64步以及自己的加载、推理、剩余迭代、完整审核与IO**。不能让R0付64步而NN免费使用该状态。分开报告“实际批次总费用”和“每条独立路线费用”，避免共享结果漏算或全批重复计费。

列冷N=1、N=8、N=100和break-even：本轮数据、前段训练样本构造、单候选训练、setup/load、推理、前后GMRES、验证/IO都计；训练不除以8冒充N=1。共同旧FE／CSR构建unknown继续单列，不能从有限包推导原尺寸48h。四臂研发总费也单列，不藏在线外。所有路线都不合格时不再额外计时，NN20明确NOT_DEMONSTRATED。

### 4.4 用已有误差确定局部模型的边界，失败不只交测试日志

终测冻结后，做一次保存数据分析，不新增求解预算：比较前64步、网络修正后、最终的trace／内部及局部／跨cell完整误差，列q_r与q_e是否背离。用固定decoder的三个小矩阵检查实际秩和输出投影残余；每个矩阵最多900×64实数，每模型每类型最多一次小SVD，必须计时间、对象和峰。只准诊断，不生成在线basis／预条件器，不做全局QR、全参数Jacobian或大矩阵SVD。

若在去除右对角尺度、转回canonical的坐标下做投影，明确这是**变换后坐标范数的表示诊断**，不是原η的严格下界，也不是可由局部输入实际预测／可消除的误差；不能再次把“可表示”冒充“可求得”。固定decoder范围投影受其学习结果影响，不可据此宣布所有宽32网络的最优下界。再报告输入两跳可见范围和完整输出／激活随cell数增长的内存公式，禁止展开原尺寸图、345M向量或体积作用。
