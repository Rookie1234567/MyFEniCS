## 2. V44究竟证明了什么

### 2.1 原残差小，完整解仍不准

这是固定64hex／p6／q15／三tag／λ0.7nm的有限代数试验：45000 native行、42624独立行、2376 slave，保存的原体积A没有完整DtN边界。制造参考e给出r=Ae，全部路线共享从零开始的64步GMRES，再比较一次模型修正及剩余64步。ρ是代回原方程的相对差值；η是全部独立有限元系数相对制造参考的差值。二者必须同时通过，不能把小ρ等同于准确场。

### 2.2 两个结构限制值得检验，但尚不是根因证明

固定NN-E的face decoder为120×32实矩阵、内部decoder为900×32，实测rank均32；内部误差变换后投影仍剩0.935858..0.955755。CL-E内部900×64、rank64，仍剩0.910736..0.923859。12个小SVD的比例重算吻合；这是去除原右对角尺度、再转实体坐标后的表示诊断，**不是原η下界、可消除残差比例、所有同宽网络最优界或训练可达到的结果**。本审阅未重跑SVD。

两跳只看19..57／496个节点；没有远距离输入消融，因此不能宣布它是唯一根因。另一可检验假设是：把整个42624系数残差归一到单位范数后，单个通道很小，tanh可能主要处在线性区，解释NN-E≈RL-E；现有记录没有逐层激活统计，不能当已证事实。V45固定新尺度并记录激活，不扫描尺度直到赢。

将这两点合起来，值得做**一次**全矩分层候选和控制；不值得重复同一两跳宽32初始化／loss权重／训练步数。新候选保持原A和严格η门，若仍失败，关闭该候选，不继续把同一有限微型问题包装成连续“进展”。

### 4.2 具体新表示：完整矩通道、稀疏分层，不求传统粗逆

以完整edge／face／cell的m=6／60／450个复矩为单位，不裁矩，不学习每个DoF专属embedding。把c=Jᴴs拆成实虚2m通道，取共同标量γ=norm(c)/sqrt(42624)，以c/γ作为输入，最后乘回γ；精确零输入旁路为零，不用大floor掩盖小输入。γ仅调整网络内部尺度，不改变物理rhs、D、损失、停止容差或最终checker。三新模型都用相同γ，线性路线需验证γ在输入输出中抵消后仍为实线性。

固定如下一个架构，不扫宽度／层数：

1. 每种m共享无bias方阵encoder `2m→2m`，逐通道φ；完整通道一直保留，最后无bias方阵decoder `2m→2m`。φ在NN为tanh，在LIN为identity。不存在每个cell强制经32实维输出的窄层；这只是结构能力，不证明能学得逆。
2. 使用已保存entity key `(dimension,direction,i,j,k)`，按edge三个方向、face三个方向、cell一类分成7组。空间桶从整数格坐标每轴除2取整开始，逐层除2直到整个有限域共一个根桶；空组均值定义为零，真实计数保留，父均值按子桶真实实体数加权，不能用不等大小桶的均值再作等权平均。对各组逐层求完整特征均值，再广播回所属实体，NN-H／LIN-H取全部层的等权平均c_i。NN-L仅取最细桶的均值。不得建N×N注意力或全局dense basis。
3. 为交换不同类型内容，每桶的7组均值按固定顺序拼成1296实通道，通过共享无bias `1296→64→1296`，中间用同一φ。NN-H／LIN-H在根桶计算并广播；NN-L在最细桶计算并广播。缺失组填零并记录，三模型同一权重形状；只有信息范围不同。64是跨类型汇总通路的宽度，**不是全部输出必须穿过的唯一通道**。
4. 每类型用两组可训练逐通道系数a、b，计算 `h2=φ(a*h+b*c_i+u_i)`，decoder输出完整实虚矩y，再映射`δ=γ D J y`。decoder初始精确零，a初始1、b初始1，encoder及汇总矩阵一个预登记seed、同一初始化规则；三臂初始参数字节相同。训练改变全部实际使用的组，零decoder第一步hidden梯度为零按链式法则处理。

此设计约**1817040实参数**，上限2000000，权重约14.54MB，参数／梯度／Adam双矩至少58.15MB，另计激活及副本。权重共享不随cell数增加；这是本轮唯一容量增大，不是把旧width32悄悄改成无限预算。固定900维完整通道的成本必须实际校准。

J保持现有精确坐标约定，包括内部native基；桶是模型的特征聚合，不是物理积分／FE粗空间，也不宣称Floquet相位或所有cell方向的物理协变。必须保存每个master归桶、类型、计数、周期折叠与输入／输出次序，检查不重复slave、不改J或原A。升规模时方向、材料、相位与owner接口尚须另外资格化，不能用这次有限代数通过代替。

这里没有装配p1算子、Galerkin逆、image-QR或局部新LU；分层只移动残差信息，其是否帮助消除误差由原方程与独立η验证。不得把它改造成传统多重网格求解器来替代神经试验。

### 4.3 同轮先核机制，再真实训练和完整终测

先在有限保存图完成必要定点检查，随后连续训练，不因普通bug交回：

- 完整矩覆盖、bucket计数与父子关系；聚合／广播的真正代数转置内积门≤1e-10，平均与转置的计数权重不能混用。用跨最远桶非零扰动证明NN-H／LIN-H具有真实内容通路，NN-L对应内容通路应为零。此项**固定γ**，排除全局归一化标量造成的伪“长程证据”；部署仍使用共同γ。
- 独立构造方阵decoder／局部分支identity见证，说明没有强制32维输出瓶颈；不做全局Jacobian／QR／SVD，不把见证称为训练已找到完整逆。记录逐层输入RMS、tanh导数分布和饱和比例，检验非线性是否实际工作，不为好看改尺度。
- 复用原A/Aᴴ autograd链；新架构全loss做3方向×3步长全向量FD，至少相邻两档≤1e-5，非零VJP操作尺度≤1e-10及batch1/2一致。至少一个方向仅作用于远距离汇总参数，并另有完整输出矩参数见证。诊断可用冻结非零decoder权重，正式训练恢复预登记零decoder初值。旧12port梯度不变则复用hash，避免重开FE接口循环。

三个新模型同混合目标`L=(q_e²+q_r²)/2`，其中q_e=norm(δ−d)/norm(d)，q_r=norm(s−Aδ)/norm(s)；完整系数与原native残差，不裁内部／难样本，精确零分母规则沿用V44。各128次Adam、batch2、lr1e-3、原betas/eps、FP64、固定16样本循环；checkpoint0/16/32/64/128，按validation median q_e、max q_e、median q_r、早step顺序选择。一个seed、一套超参数，不加训练数／扫描。普通软件失败从一致参数＋Adam边界恢复，动作、费用、已完成更新不回滚；不得再只支持任意`update<16`而把后期有效checkpoint当无法恢复。

三份新权重、CL44身份和五路线都冻结后，新heldout8分别执行；按路线独立进程串行加载，完整保存z64、s、δ、最终z与原残差。全部终测actor退出后独立CHECK才打开e，严格核对40个唯一sample/route及source、RHS、split、权重、slave、ρ和η。每路线8项均须ρ≤1e-6、η≤1e-4和完整约束通过，不能以一项或一个子组授资格。

主比较是NN-H对LIN-H（非线性）、NN-H对NN-L（远距离内容）、NN-L对既有局部结果的结构变化；后者不同数据只作背景，真正优劣使用本轮共同R0／CL44。所有神经作用都是64步后的warm correction，不宣称NN独立zero-trace求解。R0才是全程无学习的零起点路线。
