## 3. 为什么安全组合仍可能更慢；为什么不再试一次旧J

令A为原端口闭合后的trace算子，L为八块逆，J为既有image最小残差修正，`AT=UR`。组合的确满足：

```math
B=L+J(I-AL),\qquad r_B=(I-UU^H)(I-AL)r.
```

它只保证**给定同一个r时，单位局部步后再作粗校正不会增大该次二范数残差**。GMRES使用的是一整串AB作用构成的搜索空间；换成B会改变后续所有方向。L和B的Krylov空间一般没有包含关系，因而不能把单次最小残差性质外推为多步优势。D_L安全也不能保证非正规算子的完整迭代收敛速度。现有证据没有证明“粗空间全无用”或唯一病态来源。

[冻结残差覆盖记录](outcomes/records/frozen_residual_image_coverage_v24.json)对LW／LZ最终残差给出U中**平方范数**比例0.00446689523／0.22558105827。本次只重算标量关系，理想原像关系下再作一次J的范数下降约 **0.223595%／11.998924%**，不是0.4467%／22.5581%的范数下降。相应Schur约2.4965233e-6／0.07161234，仍不可能仅凭该步达到1e-6；这些是derived预测，**没有实际执行该修正**，场／功率效果未知。

因此不授权再跑旧J、改同p1测试方式、扫描scalar-tau或延长LC。也不把这些局部残差覆盖量当作trace误差表示能力、条件数或全局谱。V22误差表示约98.99%与V23可消除暖残差平方约0.024%之间的区别继续有效。

## 6. V25的唯一研究问题：现有局部方向还有多少可消除残差

response_v24提出“块内／跨块作用分账”。**仅作范数分账不够作为下一轮的唯一结论**：令D为八块原主块组成的块对角矩阵，A=D+C，q=Lr，则精确算术中Dq=r、`r-Aq=-Cq`。局部精确步后残差来自跨块作用是代数恒等式，本身不能判断应加重叠、改接口还是训练网络。

本轮把问题收窄为可证伪的一点：**八个块分别给出的方向，经原A作用后，是否包含当前残差的大幅削减方向，只是统一组合没有利用；还是这些方向本身就缺乏足够的残差消除能力？** 为此保留块的独立方向，不加入旧T／U方向、不更改p1空间、不做新GMRES或网络拟合。

### 6.2 一次局部解、八列作用及正确的比较

先以通俗方式理解：把原来一次相加的八块修正暂时分开，看每块在全域方程中产生什么响应；最后求这八个响应对当前残差能达到的最好线性组合。这样可分别检查“方向无用”和“方向有用但组合不佳”，代价是每个样本一次L8和8次原A作用。

```math
q_j=E_j^H A_j^{-1}E_jr,\quad q=\sum_{j=1}^8q_j=Lr,\quad
V=[Aq_1,\ldots,Aq_8],\quad v=V\mathbf1=Aq.
```

每个目标块i登记`E_i A q_j`的8×8来源响应：对角作用应近似r_i；记录各项范数、相干和、复交叉项及相消比，保留行列含义／固定分母。不能把范数之和当矢量和，不能将`E_i A E_j^H`误设为共轭互伴，也不能把人工分区边界解释成新物理边界。

诊断只比较三个量：

```math
\eta_{unit}=\frac{\|r-v\|}{\|r\|},\qquad
\eta_1=\min_{\alpha\in\mathbb C}\frac{\|r-\alpha v\|}{\|r\|},\qquad
\eta_8=\min_{c\in\mathbb C^8}\frac{\|r-Vc\|}{\|r\|}.
```

eta1用解析最优复系数，不扫描tau、步长或线搜索；只作区分方向与幅相的控制量，**不部署新的scalar-PC**。eta8是这八个残差依赖方向的非神经上限；不是在旧1248维p1空间中换测试方式。V5曾用旧p4／252重叠块的B、C、Z做同残差反事实，方法论不能冒充新发明；但它没有测试当前0.7nm原p3八个完整主子块分别产生的方向，本次新信息仅限这一明确区别。

全程complex128，不形成正规方程VᴴV求解或fine n×n矩阵。固定列范数均衡，只改坐标不改方向集合；用至多8列薄QR／小SVD检验秩与最小二乘。相对奇异值门限固定1e-12；零列、秩不足或全体响应未超过64eps运算尺度时如实记诊断秩／数值分辨率不足，不扫描阈值、不截秩包装成新可逆PC。可以报告已分辨的投影范围，但不能把不稳定系数作为立项正信号。若用[SciPy 1.11.4 lstsq](https://docs.scipy.org/doc/scipy-1.11.4/reference/generated/scipy.linalg.lstsq.html)，显式固定driver／cond并自己重算残差；其返回的residues空数组不能当作零残差。

原作用线性重组、对角主块作用、QR重建／正交性按运算尺度≤1e-10；用新一次原A作用复核组合q和最优组合的真实残差与薄预测，差/norm(b)≤1e-11。另报按当前norm(r)的相对差，避免将大b归一化掩盖微小残差下的不确定性。固定舍入余量内应有`eta8≤eta1≤min(1,eta_unit)`；LS驻点缺陷按运算尺度≤1e-8。r=0、v=0和近零列显式分支，禁止零除或用epsilon悄悄改定义。

只保存方向、响应、系数和诊断残差，不将它们登记为新求解终态、不作FE场恢复／RTA／参考验证，更不向旧V24队列反馈。因系数随r求出，若未来部署映射通常是非线性的；不能直接塞入旧固定线性GMRES右PC并宣称线性，外层接口必须在后续设计中单独资格化。
