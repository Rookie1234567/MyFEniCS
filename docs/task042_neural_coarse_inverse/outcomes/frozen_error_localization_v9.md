## 误差身份与齐次恢复

内部恢复会加回由载荷产生的固定特解。因此把误差直接交给默认恢复，会额外加入一次特解。正确做法是相减两个完整恢复场，或给误差使用零内部载荷：

```math
e=z_*-z,\quad r=b-Sz,\quad r_*=b-Sz_*,\quad Se=r-r_*.
```

```math
\delta u=F(z_*)-F(z)=F(e)-F(0)=\operatorname{recover}(e;\,rhs_i=0).
```

## 原方程怎样响应同一个误差

体行的两个项分别来自体场和端口未知量，端口行比较场提取与模态响应。必须先组装共享贡献再求范数；本轮原作用为：

```math
a=V\delta u,\quad c=B e_\alpha,\quad d=D_p\delta u,\quad h=H_p e_\alpha,
\qquad [a+c;-d+h]=r_{aug}-r_{aug,*},\quad n-n_*=a+B H_p^{-1}d.
```

Dp是原端口提取，Hp是原40维端口块；它们分别不同于V8列尺度D和凝聚Hhat。小Hp求解仅用于审核。交叉项及方向增益采用：

```math
\eta_{body}=\frac{\|a+c\|}{\|a\|+\|c\|},\quad
\eta_{port}=\frac{\|-d+h\|}{\|d\|+\|h\|},\quad
\gamma=\frac{\|Se\|/\|e\|}{\|Sz_*\|/\|z_*\|}.
```

抵消可能包含正常物理平衡，本批不能据此宣布奇异、条件数、舍入灾难或唯一根因。gamma只比较这五个固定误差与参考方向的代数增益，不是最小奇异值或通用误差界。V内部curl/mass作用未拆解；表示上限与优化过程机制仍INCONCLUSIVE。
