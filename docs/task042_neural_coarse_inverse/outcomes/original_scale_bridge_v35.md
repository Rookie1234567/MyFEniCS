# V35原尺寸桥接：固定局部因子不能原样放大

固定七块且每块未知量扩大f时，代数载荷约1.591420032e9*f²B、一次局部solve约f²、原构建约f³。仅因子满足2e12B也需f≤约35.45，尚未计packet、恢复、端口、Krylov与审核；这是条件排除式，不是目标DoF或可行性预测。若错误地把体积比85034当f，因子约1.15e19B，显然超2TB；真正目标f仍unknown。

改为固定块上限时，应使用预算`32*sum(n_b²)+pivot+packet+Krylov+全局耦合+port+恢复/审核+IO`，其中32来自A和LU各complex128。构建／读取及local solve可随块数近线性，但全作用、全局通信及迭代数需要独立尺度校准。V35最终外域平方残差占99.19%，不能假定块数增加后迭代保持256。目标48h的构建、单步、收敛步数、物理审核和完整端口存储均没有闭合；结论NOT_QUALIFIED。

## 失败后的替代接口，只作纸面设计

原A是40端口消元后的trace作用。J与六外域之间有传播；当前用外域六块对角解代替真正剩余算子。

```math
S_O=A_{OO}-A_{OJ}A_{JJ}^{-1}A_{JO},\qquad
g_O=r_O-A_{OJ}A_{JJ}^{-1}r_J.
```

未来周期／层次全局逆必须消费`g_O`及canonical外域行序（14256行），保留原Floquet pullback复相位、共享实体和所有cell贡献，并在同一端口闭合A下返回外域修正。再恢复J=`A_JJ^-1(r_J-A_JO*x_O)`，形成完整trace、按原Hhat闭合40port、恢复原内部特解，并由旧oracle重算b−S*z、native/port/recovery/MPC。Hhat不是原Hp；不用F=Cᴴ假设。它必须先给出匹配身份、任意RHS作用／伴随、容量及完整N=1审核，不能直接复制dot不同p4/mesh/port对象。本轮没有实现另一套求解器，也没有新A作用作诊断。

## 20%神经收益的必要成本条件

网络若只预测固定旧列空间系数，不能超过该空间精确LS；若压缩局部逆，它可能降低存储／solve费用，却不能自动补全上式长程耦合。必须先有同正确性、完整传统基线。

```math
\frac{T_{NN}}{T}\ \geq\ 1-f+\frac{f}{s}+\frac{C}{T},
\qquad f(1-1/s)-C/T\geq0.2.
```

这里T为合格N=1全费用，f为可替换exclusive份额，s为加速，C含数据／训练／构建／推理／额外精确校正及IO；若迭代数增加还要另扣。T、C以及额外迭代仍unknown，不能取C=0授予资格。本次56.797606099s solve／188.162088667s actor约30.18%只是失败actor的代理；即使假设无新增费用和不增加迭代，也需solve约2.96倍加速才可能省20%，实际不能据此认定NN可行。PC的129.5658s包含作用及IO，不全部属于可替换solve。

同峰口径下，actor峰20%约421.60MB，至少需要在峰同时存活的对象中净去掉这么多；约占当前因子载荷26.49%。仅把某单因子减20%，或者将内存转移到网络／激活／optimizer／数据，不满足整树峰20%。样本峰、页缓存与allocator变化仍需实际配对。

本轮无训练、模型读取或NN对照，神经资格NOT_DEMONSTRATED。唯一下一建议是匹配外域Schur全局传播接口与原尺寸容量校准，先资格化完整传统解；不再追加当前固定块族的方向／周期，也不自动开始网络压缩或最大模型。
