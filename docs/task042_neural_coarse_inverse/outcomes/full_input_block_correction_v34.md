## 方法、对照与审核

局部块解只能在一个区域内消除方程误差，未必消除区域间耦合。这次把外域原残差直接交给六个外块，再用联合块J=[5,7]抵消回传作用；它检验这项信息是否比旧回流或七区直接相加更有效。缓存省去六套外块重载，付出的真实新费用是J读取与反馈求解、原作用及审核。它不包含神经学习，不能把传统残差改善归给网络。

```math
u=L_O r,\quad k=B_JAu,\quad \delta=u-k,
\qquad q_{\mathrm{full}}=q_{\mathrm{ret}}+\delta,
\qquad q_0=q_J+u.
```

以下rho均为校正后残差范数除以当前输入残差范数，小于1才是改善；不是最终物理b归一化的求解合格门限。外域单独比将J残差置零后检验同一补项，无第三样本。每态Au、Ak、Aδ、Aq_ret、Aq_full、Aq0均重新使用原作用，旧缓存只作独立配对。
