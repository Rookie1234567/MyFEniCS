## 2. 主门及其严格否定范围

η是完整独立系数向量的相对欧氏误差，trace误差单列以免内部占比掩盖丢失；ρ是全部原native行的显式残差，相对每个未改变的完整b。系数平方和不是电磁能量，实体方向不是Cartesian场分量。所有6912-row掩码保留同一复系数的实虚、共享master只选一次，全部内部保留；40见证literal物理MPC误差0、原carrier slave0。

```math
c=J^H e,\quad e_M=JMc,\quad b=Ae,\quad
\eta=\frac{\|Mc-c\|_2}{\|c\|_2},\quad
\rho=\frac{\|Ae_M-b\|_2}{\|b\|_2}.
```

50%最小遗漏系数平方和`4.18810193e-7..5.11892674e-4`；η为门限6.47至226.25倍，trace误差为门限12.92至426.65倍。已通过正交桥检查，所以能否定这些样本、固定canonical坐标和50%基数预算下**任何仅删系数的掩码**达到本系数门。不能否定别的坐标／可学习编码、不同数据或不同空间；80%不能取代主门，ρ失败不证明子空间重求后的最佳残差必然失败。没有QR／拟合／迭代救场。
