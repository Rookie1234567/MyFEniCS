### 4.2 一个小网络，两个必要对照

用保存拓扑构建边、面、cell内部三类节点，节点分别带完整6／60／450个复残差矩；周期等价节点唯一owner，计算slave为0，cell—实体关联只用实际拓扑。网络先压缩节点残差，向相邻节点交换两轮短特征，再输出每个节点的全部修正系数。这样参数数目不随cell数线性增加，但中间特征、通信和完整输出仍随规模增长，必须计费。没有全局P/Q/A薄矩阵、全局QR或逐DoF可训练embedding。

冻结单个架构：两轮邻接消息、宽度32、tanh、总可训练实参数≤100000、CPU FP64实虚通道。几何／材料输入限真实轴宽、类型、相邻tag和相位等固定局部身份；不输入全局行号作为学习特征，不输入精确解／误差／旧REF7。输出投到独立canonical完整系数，再通过已验桥得到native存储／物理展开。不要为构图复制全目标数据；只用64hex。配置、seed、归一化、聚合权重与全部变换在正式训练前提交冻结，无宽度／深度／激活扫描。

### 4.3 数据、真实伴随梯度与训练

冻结train16／validation4／heldout8个右端。由独立seed、固定的局部与跨cell／缓变三维误差生成`r=Ae`；这些是代数manufactured数据，用于覆盖内部、trace和长程方向，不是假称真实入射解。生成后训练端只得到r和算子；e隔离封存，终测冻结后仅checker使用，禁止监督拟合e或按参考误差选择checkpoint。不得将有限CSR转为全局dense，也不得物化完整参数Jacobian；JVP/VJP使用有界重算。各集合按完整seed／支持区域／误差生成族分离，不把同一e的相位或幅值缩放拆入训练和heldout；相位／幅值增强属于同一原样本并如实计数。至少2个heldout为跨cell缓变方向，避免只证明局部高频样本有效。

零RHS独立精确返回零；非零输入归一化和输出尺度固定，复相位／幅值缩放作明确反例与终测。NN不自动是复线性算子，不要求凭模型结构宣称逆的线性；必须报告实际行为并仍以最终原残差裁决。R-LIN须证明复线性。三条路线完全相同的r、精度和独立行集合，不能删难样本。

```math
\delta_\theta=F_\theta(r),\qquad
L(\theta)=\frac{\|r-A\delta_\theta\|_2^2}{2\|r\|_2^2},\qquad
\nabla_\theta L=-\frac{\operatorname{Re}[J_\theta^H A^H(r-A\delta_\theta)]}{\|r\|_2^2}.
```

FE与ML保持隔离环境，packet交换；可在ML进程只读使用已存有限CSR／同一稀疏作用作损失回调，但必须绑定原字节并先与生产A/Aᴴ完整向量配对≤1e-10，不在Torch中重建另一套物理。稀疏CSR、原矩阵与loader副本的驻留和加载全部计费，不把它们藏成“离线免费”。不能在ML进程注入另一ABI的PETSc/MPI。

正式训练前只做一次必要导数资格：完整canonical↔native映射及其dual配对≤1e-10；3个固定实参数方向，各用3个预登记相邻步长检查完整向量JVP，至少两档相对差≤1e-5，并保存绝对值／近零规则；VJP双线性运算尺度差≤1e-10，结果尺度和抵消另外报告。固定r，验证整条`NN→全FE系数→原残差→Aᴴ→NN参数`；B使用保存的C/D、一般非互伴反例和非零g验证端口损失导数，不重建8hex／端口积分。不要以原始scalar-loss差分单项重复V12困局，也不重做已有无关MPI或全拓扑资格。

门通过后**同轮实际训练**，不能只交冻结网络推理或gradcheck。R-NN与R-LIN各最多128次更新、batch2、单个初始化seed；固定Adam学习率1e-3及其默认矩参数，禁止学习率／seed扫描，checkpoint在0/16/32/64/128。保存每步真实loss、参数hash、梯度范数、action／adjoint调用和耗时；分别列encoder、消息／hidden和输出组参数改变量，只有输出头改变不能称本轮非线性表示已训练。训练本身只优化原残差；validation选择最低原残差checkpoint，heldout只在权重冻结后打开。任一数值非有限立即保存并诊断，明确软件错误可同轮修复，不用换seed掩盖。

研究继续门在更新32之后按validation判定：若NN原残差中位数相对其起点没有下降至少20%，且最坏样本仍不改善，则停止该候选后续更新，分类`TRAINING_EFFICACY_NEGATIVE`，直接完成冻结评估和成本分析；不把它称为所有NN不可能。若下降满足，继续至上限，不在更新一次后就交回。这个残差下降门只用于本轮早停研究效率，**不是NN增益门**；正式NN门一直是同正确性完整成本20%。

### 4.4 冻结终测、同一传统清理和成本裁决

权重冻结后，对8个heldout各执行R0／R-LIN／R-NN，传统清理上限和容差完全相同。若有路线在某个右端提前收敛，记实际工作而非补齐预算；未收敛保持FAIL，不放宽门、不追加128步。至少保存初始修正前后及最终的完整向量、原残差、轨迹和每次调用，所有输入／矩阵／权重／source可追溯。没有教师在线解、局部LU补救、global factor、image-QR或旧warm包。

本有限代数试验的严格门：全explicit原残差≤1e-6，封存e的完整独立系数相对误差≤1e-4，约束／slave与完整覆盖通过；有已有可消费质量／curl参考矩阵时同时报告完整FE误差，但不因此启动新积分。近零规则预登记，不拟合相位。**系数门／有限体积门不是原目标全场、端口功率或h/p收敛资格**；8hex的12mode梯度检查也不变成32060mode物理求解。

给每个RHS三条路线完整时间、最大同时树峰、原残差与误差，不只给平均loss／迭代数。用于正式比较的各路线必须通过相同的8个heldout门；否则只可报告逐项诊断与预算内研究信号。若全部合格，按一次新进程对预先冻结的整组做最终计时，不为了挑中位数无界重跑；共享工作站干扰如无法隔离，性能结论仍INCONCLUSIVE。

成本列N=1、N=8、N=100及break-even，且明确N=1的训练／数据不能除以8或100：

```math
T_{NN}(N)=T_{data}+T_{train}+T_{setup}+T_{load}
+\sum_{j=1}^N(T_{infer,j}+T_{cleanup,j}+T_{audit,j}+T_{IO,j}).
```

R-LIN自己的训练／setup同样计费；共同FE构造如沿用旧包，列“本轮增量”与“从零准备”两账，旧构造成本未知时不能补造冷N=1。无相同正确性或全成本口径不全，即使迭代数减少也不授NN20%。最佳非神经路线、冷N=1、峰内存、另一指标是否合规四项各自作结论。有限合格20%也只能称pilot证据，原尺寸资格保持未获。
