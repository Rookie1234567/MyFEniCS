## 4. 对“跨界回流”提案的独立判断

执行者建议：先在联合块J解一次，再让外面的六个旧块处理联合响应在外域造成的不平衡，最后回到J补偿这一步对内部的反作用。它改变了通信路径，会生成原九方向不一定包含的向量；复用已有因子但增加读盘、原方程作用与三角解。**值得最后一次固定单步诊断，尚不值得新的迭代campaign或NN训练。** V26的外部增长提供检验动机；并不保证该回流能抵消它。

本报告修正response_v26提案的两处边界：**基线必须是已经取得的九方向，不能再对旧八方向计算“新收益”；固定线性不意味着可逆或能覆盖完整误差空间。** 为避免与集合J混淆，把联合修正算子记作B_J，外域O为其余六块。

```math
\begin{aligned}
A&=K-C\widehat H^{-1}F,\qquad A_{JJ}=E_J A E_J^H,\\
B_J&=E_J^H A_{JJ}^{-1}E_J,\\
L_O&=\sum_{b\in\{0,1,2,3,4,6\}}E_b^H A_{bb}^{-1}E_b,\\
q_J&=B_Jr,\qquad w=L_O A q_J,\\
d&=-w+B_J A w,\qquad q_{\rm ret}=q_J+d.
\end{aligned}
```

这里E_J只取J内行，转置共轭负责注回全trace；所有原A作用都包含完整端口消元，方向为齐次方向，不带原内部特解。一次反馈没有自由tau、训练参数或顺序选择。

在精确算术、原主子块一致时，内部反作用会抵消：

```math
E_J A d=0,\qquad E_J A q_{\rm ret}=E_Jr.
```

因此真正新增的是一个**不改变内部原方程响应、改变外部响应**的方向d。已有q_J在九方向中，加入q_ret与加入d得到同一扩展空间，二者不能当作两个新候选扫描。记c为原联合响应的外部部分，S_OO为精确消去J后的外部方程作用，则：

```math
\begin{aligned}
c&=E_O A q_J,\\
S_{OO}&=A_{OO}-A_{OJ}A_{JJ}^{-1}A_{JO},\\
E_O A q_{\rm ret}&=c-S_{OO}E_Ow.
\end{aligned}
```

这是一轮外部反馈，S_OO不要求Hermitian或正定，L_O也不是其精确逆；没有收缩保证，可能放大外域残差。上面是代数推导，尚无V27实测；实现必须以原A验证内部抵消和实际外部变化，不能根据推导填PASS。

更关键的是，q_ret始终只依赖r在J内的3888个分量：对所有J支撑外的r它返回零，算子rank至多3888，小于18144。**它不是全空间逆，不能单独作为完整GMRES右PC。** 若将来与具有全空间作用的基线组合，须另审覆盖、稳定性、整体费用与完整物理，不能把本次增量LS随r变化的系数称为固定线性PC。
