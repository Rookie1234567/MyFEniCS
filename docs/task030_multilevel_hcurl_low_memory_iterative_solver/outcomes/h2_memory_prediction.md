# h2 内存预测与实测校准

最终候选是 `75D wave coarse + ILU0 overlap Schwarz + symmetric pre/post sm2 + subdomain-local shift + factor-only storage + FGMRES restart90`。

| 网格 | FE DoF | 含 R/T/A 峰值 |
|---|---:|---:|
| h5 | 44,698 | 1.696136 GB |
| h3 | 198,438 | 3.807503 GB |

使用两个独立的两点模型外推 h2（615,108 DoF）：

- DoF–RSS 仿射模型 `M=a+bN`：中央值 **9.5298 GB**；
- DoF–RSS 幂律模型 `M=cN^p`：拟合指数 `p=0.54250`，中央值 **7.0337 GB**。

两种中央预测都 `<=10 GB`。以较保守的仿射中央值增加 15% 工程波动，得到上界 **10.9593 GB <=12 GB**，因此 G5/G6 均通过。

h2 首次 1800 步未收敛运行峰值为 **9.342113 GB**。同一候选资格复跑在 1873 步收敛，含 R/T/A 最终峰值为 **9.374729 GB**：比仿射中央预测低 1.63%，比 Task27 的 13.080257 GB 低 **28.33%**。运行始终低于 10.5 GB 软警戒，更未触及 12.5 GB cgroup 上限；两个预测模型因此得到实测校准。

实测只证明此固定物理问题和 MPI4 分区；不能把 9.375 GB 外推成所有材料、角度、波长和分区都保证低于 10 GB。
