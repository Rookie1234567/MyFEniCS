## 固定模型与问题

本实验在 phi90 三维 Maxwell 光栅模型中，把一个固定单元内部的多项式阶次从 p5 提到 p6。这样能让单元内部场表示更灵活，但增加独立未知量；本实验没有把该单元再切小（没有 h 分裂）。目标单元的全局编号是 cell 8，森林网格编号是 root 4；它们是同一单元的两种编号，对应 box `[16.5, 5, -10] → [33.5, 10, 0] nm`。模型使用 50×50 nm 周期、140 nm 高度、13.5 nm 波长、算子积分 q15、入射/端口积分 q28、R13 与 612 个模式；场比较使用 q8/q10，并以固定 Y6_1 参考场比较。A_volume 的材料吸收 form 使用 q15；用于区域体积核验的 form 使用 automatic 阶次，二者不混称。合同配置 normal correction=1、extra correction=0；F 实际完成了一次 normal correction、没有 extra correction。

## q8/q10 配对结果

J 汇总归一化输出分量中最差的一项；J≤1 是输出精度门。G 衡量全域电场及其旋度相对参考场的差异，越小表示与这个离散参考越接近，但不代表连续真误差。冻结的输出变化阈值为 εJ=`0.12716416232413652`、εG=`9.088158796603444e-6`。

同一固定采样点上，R9 的 J/G 为 q8 `4.065061945224269 / 3.995683423458671e-5`、q10 `4.065061945224269 / 3.9956834234581814e-5`；历史 H8 为 q8 `3.9745473239816143 / 4.547357272406127e-5`、q10 `3.9745473239816143 / 4.5473572724057846e-5`。P8 的 q8/q10 值见表；G 相对 H8 略低而 J 更高，整体每新增 FE 的区间仍不能排出优胜者。

两个阶次的 ΔJ、ΔG 都小于各自冻结阈值，表示增益尚未达到预先规定的冻结可分辨尺度。更关键的是，实际精度门没有通过：`power.R00_s` 与 Y6_1 的绝对差为 `4.020864574738603e-6`，高于 `1e-6`；J=`4.020864574738603` 也高于 1。这个偏差是最终未接受的具体原因，不是工程运行失败。

本轮 P8 的新增自由度为250；历史 H8 新增自由度为6,268。q8/q10 中 P8 的 ΔJ/FE 区间都跨过0，且其下界没有超过 H8 历史区间上界 `3.472858704001132e-5`，所以没有证据说 p 加密优于 h 加密。H8 数值来自之前绑定的历史样本；它不是本轮重新求解的对照。q8 复用了已绑定样本 SHA `5475cffe826f45217cebd8df35239f4ba8a4a5813657cf2ca7696ce871af792f`，没有重新采样；q10 本轮仅采样一次，SHA `a3f3edca3f1f07fca79c37c1823b1616d6c330c36122ebc405d47ef2f8c20a85`。旧 P5 场没有重采样。
