## 4. “理论上应成立”与当前证据如何对应

令A6、A4表示同一572通道的完整未凝聚物理算子，P是相容p4→p6延拓，PH是其复伴随。凝聚只是计算逆的实现，恢复后的方程应与这些完整算子一致。

```math
A_4=P^H A_6P,\qquad C=P A_4^{-1}P^H,\qquad
B=C+(I-CA_6)H_6(I-A_6C).
```

若精确满足Galerkin关系且粗逆精确，则粗修正后限制回p4的残差为零。实际粗解c的误差可分为：

```math
r_4=P^Hg-A_4c,\qquad D=A_4-P^HA_6P,\qquad
P^H(g-A_6Pc)=r_4+Dc.
```

实际浮点计算还需记录求和/相减顺序误差。这说明首先要修复r4或D对应的实现/精度问题，不能因为公式正确就忽略检查。过去P64反例表明把数值方向矩阵的逆当成转置会放大误差；修复采用 `solve(Tf.T, P_ref @ Tc.T)` 并保留PH伴随。端口联合精化则对原块系统 `[V B; -D H]` 同时校正两块残差（此块D为端口映射，与上式算子差D含义不同）。

**平衡恒等式本身不保证短波Maxwell问题的外层迭代一定很快。** 它不自动提供H6对所有未处理误差的谱控制，也不消除有限精度、粗算子条件性或参数依赖。应分两次判断：先关闭实现/原残差门，再评估正确PC的收敛效率。当前没有证据证明“BAL_H数学结构不成立”；也没有证据证明把末次A4超限简单归为舍入噪声就是正确的。
