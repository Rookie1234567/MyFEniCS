# R0–R6 成本、修正贡献与停止边界

| 对象 | 实测结论 | 资格边界 |
|---|---|---|
| R0 旧 PC 的同机剖析 | 7 次完整调用，首个 warm 调用不进入主中位数；其余 6 次中位 22.021386729524238 s | 解释原“22 秒”口径；不是完整求解 |
| R1 等价实现 | 7/7 完成；主中位 74.87089344408014 s，为 R0 的 3.3999172878472805 倍，要求 ≤0.75 倍 | `EQUIVALENT_SPEEDUP_INSUFFICIENT`；数学等价通过、速度 Gate 失败 |
| R2 | `not_run` | R1 未通过速度 Gate，按 review 自动跳过 |
| R3 唯一 LIGHT 完整求解 | 零初值；solve 7200.255611149943 s 触发停止，全流程 7966.278611822054 s | `PERFORMANCE_CONTROLLED_STOP`；更便宜但数值未资格化 |
| R4 / R5 | `not_run` | 原始模型未取得 residual/输出 Gate；不追加非可分、direct 或 h5 heavy |
| R6 | 紧凑证据与集中回应 | 不启动第三 PC，不把停止修复当作重跑结果 |

研究对象为原始 13.5 nm、掠入射 1°、Full3D p6/h10、MPI1、80 DtN 模式。p6/p4 存储 rows 为 173802/53084，独立 rows 为 164592/48960；p4 增广参考矩阵 53164 rows，既有 volume/augmented NNZ 为 24666128/24730144。这里的辅助修正（PC）是每次外层迭代用来消减方程误差的一段计算；单次便宜不意味着达到相同误差所需总时间同比下降。

R1 保留原 PC 数学作用而替换局部计算实现。R3 则使用审阅允许的唯一轻量组合 H6 → p4 reference → H6：H6 只在 p6 上做正定平滑以削弱局部误差，省去 S6 内的 p3/p1 多层步骤；中间仍使用原 p4 物理矩阵分解。每段方向通过原 A6 的最小残差缩放（MR）后加入，目的是避免修正反而放大物理残差，代价是额外原 A6 作用和可能较弱的中间修正。R3 改变 PC，不能叫 R1 的等价加速通过；物理方程、原 A6、输入及生产默认未改变。

B6 是 H6 使用的辅助算子，实际轻量 PC 名称是 H6–p4–H6，不是直接把 B6 当逆。两条分支已按本轮合同结束，但不能说两种算法已经彻底研究完或被否定。R1 只证明被测 S6 等价原型提速不足；后来 H6 使用的 contiguous packing 没有用于完整 S6 路线重新资格化，该项为 `not_run`，不代表没有前景。本轮不重开这条路线。

原“22 秒”来自固定输入上的完整 PC 主范围，不包含 profile 的输出检查、checkpoint 重构以及冷 setup。R0 setup 约 758.21 s、workflow 约 927.42 s；R1 setup 762.9966213500011 s、workflow 1357.110160990036 s，冷成本没有藏入热平均。嵌套计时按树解释，父子不能重复加总；未提供的 exclusive 差额不推算为零。

R0成功剖析之前的两次失败保留：第一次105.19980926497374 s，在fine_physical setup发生JIT缓存编译TimeoutError，0完整PC；缓存恢复后一次766.8361822949955 s，在profile_started遇到`vars() argument must have __dict__ attribute`的采集适配错误。它们属于实现/测量失败，不能当作算法残差失败，也不从总预算删除。各次source、原目录和hash由私有R0审计绑定，小JSON保留批次账本入口。

rho 是该段修正后/前的残差范数比，越小表示该次方向越有效；eta²=1-rho² 是消掉的残差平方比例。alpha 是 MR 为候选方向选取的复数系数。不同调用接收不同 Arnoldi 输入，统计不能连成物理收敛曲线，也不能单靠中位数证明因果。

583 个已完成 p4 回代的原 A4 真残差最大 7.058163970105702e-11，均满足 1e-10；setup Galerkin 误差 3.597817171089689e-15。**仅对 physical_middle**，在该 Galerkin 关系成立时，缩放后剩余粗空间残差近似为 `(1-alpha)g4`，其 `abs(1-alpha)` 中位 0.9499915645616905，说明准确的 p4 逆不保证细层残差得到强消减。563/582 个未缩放 middle 方向的 rho>1，因此不能据此建议强制 alpha=1。该粗残差解释不适用于 H6 pre/post。

R/T/A、A_volume、R00_s/R00_p/R00_total、全部衍射级、复 E/H、近场与参考平面均未生成 official 结果；无非可分、同离散独立 authority、p/h/M/MPI 或 Hybrid 新对照。不能宣称连续极限、production 或0.7 nm容量通过。

事后停止流程修复 `597546311feea60d61acb2a9999b706dd895dcf0` 仅对未来 LIGHT 显式启用：登记应用 worker PID 与 start ticks，核对活进程身份，只向该 worker 发一次SIGTERM，保留最多60 s安全点宽限；资源越线或宽限到期仍整树强停。真实 MPI1 小 fixture 重现旧 mpiexec 被抢先终止，并验证合作退出、不合作、资源硬停和陈旧身份五类路径；23项局部测试通过。混合测试最初的MPI继承环境失败日志保留，修复仅在测试显式传递环境；生产环境没有清洗或fallback。该修复没有重跑 R3，不改变其负结果或弥补缺失终态。

唯一主要研究 blocker 是：准确 p4 参考逆辅助下，原 A6 外层仍未在预算内达到合格残差。下一轮须先审阅有效方向与总工作量；不能用剩余预算自动换第三PC。global p4 factor仍是诊断依赖，短波物理精度、可扩展容量与生产资格均未获得。原始证据及source/hash由 [运行索引](records/run_index.json) 与小JSON绑定；大型audit、矩阵、向量和timeline保持ignored。
