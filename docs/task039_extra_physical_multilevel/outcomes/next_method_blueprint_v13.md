## 2. 实际接口划分与精确物理作用

定义 Gamma 为共享宏块独立行、当前非零 DtN 行/列支撑，以及存在跨内部 owner 体积分连接的单元内全部候选内部行的并集。其余合法独立行按唯一 owner 分成 I_i；扩张 Gamma 后重新查无跨 I_i 体积耦合，不能假设内部块对角。

| 当前结构实测 | 数值 |
|---|---:|
| p4 合法独立行 | 48,960 |
| Gamma / I | 13,092 / 35,868 |
| 共享宏块行 / 非零 DtN 支撑 | 12,108 / 1,152（有交集，不直接相加） |
| 跨 owner 体积分单元 | 0 |
| 宏块/接口 patch 数；最大原局部块行数 | 42；1,944 |
| DtN 条目数；projection/coupling NNZ | 80；各 31,968 |
| 稠密 Gamma Schur 单矩阵的派生载荷 | 2,742,407,424 B，尚未含 factor |

结构来源为正式目录的 `records/interface_structure_inventory.json`，状态 `STRUCTURAL_INVENTORY_COMPLETE`。该 raw 包只证明结构盘点；其中 `blueprint_status=PENDING_RESPONSE_DOCUMENT` 保持原样。本文件是后来完成的规则说明，不把运行时结构状态改成数值资格。

令 A=A4 已含当前体积项和 DtN，在原生独立坐标中：

```math
\begin{aligned}
A&=\begin{bmatrix}A_{II}&A_{I\Gamma}\\A_{\Gamma I}&A_{\Gamma\Gamma}\end{bmatrix},\\
Sx&=A_{\Gamma\Gamma}x-\sum_i A_{\Gamma I_i}A_{I_iI_i}^{-1}A_{I_i\Gamma}x,\\
f_\Gamma&=g_\Gamma-\sum_i A_{\Gamma I_i}A_{I_iI_i}^{-1}g_{I_i},\\
x_\Gamma&=B_Sf_\Gamma,\qquad x_{I_i}=A_{I_iI_i}^{-1}(g_{I_i}-A_{I_i\Gamma}x_\Gamma),\\
F_{\mathrm{interface}}(g)&=[x_I;x_\Gamma],\\
S^Hx&=A_{\Gamma\Gamma}^Hx-\sum_i A_{I_i\Gamma}^HA_{I_iI_i}^{-H}A_{\Gamma I_i}^Hx.
\end{aligned}
```

逐块流式作用，禁止物化全局稠密 S 或全局接口 LU，DtN 不重复添加。实际 `A_IiIi` 是内部子矩阵，需要新因子；旧完整重叠 D_i 的逆不能冒充其逆。构建前释放整套旧局部因子，不允许旧新库存叠加后绕过预算。原全局参考、材料、Nedelec/双 Floquet/DtN 与 A6 显式残差不变。

## 3. 一条确定的 reference-free 粗方向规则

每个接口 patch 使用冻结宏块与 Gamma 的交集 G_i。定义真正的物理限制 `S_i=R_Gi S R_Gi^H`，patch 外 trace 为零，但必须包含所有邻接内部 I_j 的消元贡献，而不只是 owner 的 I_i。复材料、波数和 DtN 均保留。令 D_i 为同一无材料质量对角在 G_i 上的限制，D_i 只作正坐标尺度：

```math
\begin{aligned}
T_i&=D_i^{-1/2}S_iD_i^{-1/2},&H_i&=\begin{bmatrix}0&T_i\\T_i^H&0\end{bmatrix},\\
T_iv&=\sigma u,&T_i^Hu&=\sigma v,\\
q_i&=D_i^{-1/2}v,&P_i&=R_{\Gamma_i}^HW_iq_i,\\
\sum_iR_{\Gamma_i}^HW_iR_{\Gamma_i}&=I_\Gamma.
\end{aligned}
```

拟议有界生成器用 H_i 上的厄米 Krylov/Ritz 过程寻找接近零的奇异方向，不显式形成 `T_i^H T_i`，不使用新的全局逆或 shift-invert 因子。确定性初始列取 canonical 坐标 l 上的 `sin(l+1)+1j*cos(sqrt(2)*(l+1))` 并归一；发生精确 Krylov breakdown 时，从最小 canonical 坐标单位列作正交补续接，其作用也计数。最多 32 个常驻工作向量、64 次单列 H_i 等价作用（块调用按列计数），采用厚重启保留绝对 Ritz 值最小的至多 8 对。正负成对结果先合并，按 sigma、canonical 最大分量位置排序。每个方向用原 T_i/T_i^H 的奇异对残差复核：

```math
\frac{\max(\|T_iv-\sigma u\|,\|T_i^Hu-\sigma v\|)}
{\max(\|T_iv\|+|\sigma|\|u\|,\|T_i^Hu\|+|\sigma|\|v\|,\mathrm{tiny})}
\le 10^{-8}.
```

每 patch 保留至多 8 个通过验证的最小已收敛 Ritz 奇异方向；它不保证找到真实最小的 8 个奇异值。重启、残差复核、伴随验证均占用同一 64 次等价 H_i 动作额度，不额外补动作。双边核方向从相应左右残量核查，不把 `[u;0]` 自动当右奇异向量。零/相关列用固定 `1e-12` 复数 QR 阈值删除；没有足够独立且验证合格的方向就报告谱资格不足，不延长或扫描。上述数值上限均是下一 review 的工程提案，本批没有执行。

辐射边界另保留当前非零 DtN carrier 的输入、输出方向。对每个 `u_m v_m^T` 秩一项，将 `D_G^(-1) u_m` 和 `D_G^(-1) conj(v_m)` 加入候选，按原 mode 顺序和同一 QR 阈值去零去相关。80 个条目给出最多 160 列上界，不是已测独立 rank。参考、当前三份误差的 POD、y_M、跨 RHS 历史方向均禁止参与。

各层尺度对角按 `D_(l+1)=diag(P_l^H D_l P_l)` 传递，正性和零列单独核查；它只是参考无关的坐标尺度，不替代真实场误差所用的M0。

`P=[P_local,P_DtN]`，粗作用 `S_c=P^H S P`；层间延拓为 P，残差限制为 P^H。内部延拓同时用 `-A_II^(-1) A_IG P` 流式恢复，不常驻 N6×全部方向。保留局部物理近核方向和全局 DtN 通道有结构理由，但非正规系统中仅用右奇异方向及 Galerkin 限制是否足够，仍须真实算例裁决。

## 4. 固定接口周期、分层及容量终点

Schur 消元并不提供强接口逆。下一轮首个实现拟用一次固定 V-cycle；不在其中等待 Krylov 收敛。为使调用具体可实现，首层局部平滑先固定为原物理 `diag(A_GG)` 的复数对角修正 J：相对最大对角小于 `1e-12` 的项置零并报告，其他项取倒数，不改材料或补任意正定移位。这个便宜平滑器可能不够强，是明确待验证风险，不是又增加一条候选 PC。

```math
\begin{aligned}
x_1&=Jr,\\
x_2&=x_1+PB_cP^H(r-Sx_1),\\
B_Sr&=x_2+J(r-Sx_2).
\end{aligned}
```

每个非底层一次 cycle 有 2 次本层 Schur 作用、2 次对角平滑、1 次限制/延拓和 1 次下一层 cycle。下一层的 J 用该层粗物理作用的对角；对角由构造粗作用时取得，额外构造工作计费。恢复内部时可缓存第一次消元结果，得到 `x_Ii=u_Ii-solve(A_IiIi,A_IiG x_G)`。

拟冻结底层最多 **512 行、factor allocated 64 MiB**，仍走 symbolic/allocated Gate；512 阶 complex128 矩阵本体 4 MiB，不能拿本体当 factor 或 RSS。当前第一层候选上界 `8*42+2*80=496` 列，496 阶单矩阵 3,936,256 B。未满秩或粗矩阵不可逆则停止资格化，不改 rank/移位凑通过。

若粗层超过 512 行，按体积分接口图从最小 canonical 未归属节点开始，依距离和序号确定性聚合最多 8 个邻接块，低秩 DtN 通道单独传递，重复同一物理奇异方向规则和 `S_(l+1)=P_l^H S_l P_l`。每层必须严格减维；否则标明该尺度方法未资格化并停止。单 patch 拟上限 2,048 行；更细网格需下一任务事先提供满足上限的分区，不能本轮在线扩大块或扫描。此规则解决全局粗 LU 随网格无限长大的设计问题，但尚未证明层数、局部 rank 和谱构建成本在 0.7 nm 可接受。

新接口方法的成本须从零资格化：

```text
setup = sum_i factor(A_IiIi)
      + sum_p (谱过程 S_p/S_p^H 动作及独立残差核查)
      + DtN 方向/QR + 各层 P^H S P 构造 + bottom factor
每个谱 H_p 动作含 nu_p 次内部 solve + nu_p 次共轭转置 solve
首层谱内部回代上界 <= 2*64*sum_p nu_p <= 225,792（42*42 的极保守界）
一次 F_interface = 内部右端消元 + 一次 B_S cycle + 内部恢复
若只有一层和底层，内部回代数 <= 42*(1+2+1)=168
一次 B4_new = 一次 F_interface + 2次 C_U + 2次 A4逻辑作用
```

168 中的 2 来自接口 cycle 的两次全 S 作用；B4 外包的 2 次 C_U（含已有底层 solve）和2次 A4不得遗漏。每次接口 bottom solve、低秩 DtN 归约、限制/延拓与通信仍另计。构造 496 个粗列需要最多 496 次 S 作用，即最多 20,832 次内部回代，不能从谱费用中漏掉。实际邻接 `sum(nu_p)`、谱收敛率、内部 factor allocated、粗构造时间、通信和整段外层步数尚未知；不得宣称新 setup 便宜。

方向 payload 的当前派生上界：局部 P 列 `8*42*1944*16=10,450,944 B`；全部 DtN 候选 `13092*160*16=33,515,520 B`；单 patch 32 个 H_i 复工作向量在拟上限 2048 行时为 2,097,152 B。谱 patch 顺序处理，禁止保留所有 patch 工作基；QR副本、算子临时、方向去相关、每层传递、局部和底层 factor、RSS 必须分别登记，沿用当前预算作下一轮预检起点，未审阅不自动提高。

`2TB_0p7nm_blocker_removed=false`：消除了设计上必须物化稠密全局 Schur 的要求，但局部谱构建、粗 rank 增长和 MPI 通信的实际障碍仍未排除。

## 1. 数学合同不变

仍用同一真实 A4、42 块、输出权重和完整 C_U。C_U 提供已有的全局粗修正，d 是各局部解的加权和，-t 是随后扣除的粗反馈；保存这些方向后可以改变组合系数，而不重新作用 PC。M04 衡量场的积分强度，K04 衡量经 k0 缩放的旋度能量；下式 curl6 指未缩放的 curl-curl 双线性形式对应算子。

```text
a = C_U g
h = g - A4 a
d = sum_i R_i^H W_i D_i^(-1) R_i h
t = C_U(A4 d)
B4(g) = a + d - t
Z_j = 实际右预条件调用 B4(v_j) 的输出
L = [Z, a, p_1, ..., p_42, -t]       # 至多48列
L10 = [a, p_i1, ..., p_i8, -t]       # 至多10列，不包含Z
M04 = P64^H M06 P64
K04 = P64^H (k0^(-2) curl6) P64
```

I4 仍零初值、最多四次 B4；QR/SVD 相对截断仍为 `1e-12`。参考场只评价误差和计算标注为 reference-only 的最佳场组合，不进入 PC、选择器或初值。固定 D 的离线候选在 01 上已违反场误差减半条件；不能将该结果外推为未来改变搜索方向的尺度化 Krylov 必然无效。
