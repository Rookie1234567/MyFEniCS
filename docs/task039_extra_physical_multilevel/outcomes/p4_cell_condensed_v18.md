# V18 装配时单元凝聚：执行证据

用户最新授权：完整地跑个p6h10的模型，看看结果，如果不是数值gate，那么就修正那些bug。以下两场实现失败及费用保留为续跑前快照；原重放额度不再阻断本次有明确 bug 证据的续跑。准确凝聚、原数值/物理/资源 Gate 和 observe_only 均保持，U4 正在继续，U5 仍以 original 完整通过为条件。

本轮在单元内先消去只属于该单元的未知量，再装配共享边界与原 80 端口的全局矩阵。每次新输入先处理内部右端项，做一次全局回代，再恢复全部内部未知量。这样减少全局因子需要处理的规模；局部 LU、恢复算子与装配工作区的费用仍需计入。准确性和实际内存结果由后续正式运行裁决，不能从自由度比例推断节省。

U0 包含真实两材料单元的完整张量先相加再凝聚、复数 MPC、非零内部 RHS 和端口左右耦合、完整恢复及 slave-zero、重复/线性、CSR 内容身份、owning 清理、真实 p6 dispatch，以及逐 RHS 保存与异常保留。开发中发现并修复了组合积分丢项、端口矩阵插入布局、缓存记账和测试夹具符号等问题；失败日志保留在 ignored 工程目录，尚未使用正式计算的 bug replay。

工程证据目录：`benchmarks/artifacts/task39extra/p4_cell_condensed_v18/root_engineering/`。独立检查器是 `benchmarks/check_p4_cell_condensed_v18.py`。准入检查从原始数组、范数、factor 控制和连续进程树轨迹重算；准确路线不设内存节省百分比门槛。U3 仅允许新凝聚矩阵的一个 `tau=1e-5`，不足则选择准确凝聚继续。

本地未安装 Ruff，未安装新包；没有执行全仓库 pytest 或声称 CI 通过。完整 formal source SHA、命令与阶段结果随正式证据追加。

U2 formal source 为 `e1b5a398a199cdbc7c26ce3af8645daed2eeb7d6`。全局凝聚矩阵 21,824 行、8,184,464 个存储条目，恢复 27,216 个内部坐标；CSR 内容 hash 在 factor 前后及六次调用后保持一致。完整/主三输入 RSS 峰值均为 1,785,585,664 B，相对 Q1 下降 36.8152%；库存保守峰值 1,776,346,158 B，临时预留峰值 134,217,728 B，全部安全检查通过。

凝聚装配到逆就绪为 32.9821 s，其中全局 numeric 21.5539 s（Q1 numeric 为 18.4888 s，减少内存并未让该阶段更快）。三份主输入的纯缩减—回代—恢复耗时 0.23449/0.21033/0.18422 s；原生残差评价、场度量与保存分别记录，不与 Q1 包含残差检查的调用耗时直接相除。U2 整个进程树工作流 monotonic 为 93.1324 s；历史 Q1 的 JIT/缓存与启动时钟费用单列，不能从总耗时差直接宣称算法加速。证据和全部原始 hash 见 `records/p4_cell_condensed_v18_compact.json`。

U3 formal source 为 `5e95066d80579b0e135643f9fd114bd3dcc43424`，矩阵 CSR 与 U2 完全相同。三 RHS 原 A4 残差为 0.00762755、0.000482349、0.0110374，场与旋度误差均小于 0.00025，均达到 BLR 局部准入线。34 个 BLR fronts 覆盖 85.5% 的因子条目，但实际条目只从本矩阵的 40,282,272 降到 39,333,043（减少 2.3564%）。全过程和 factor-live RSS 为 1,810,874,368 B，相对准确凝聚增加 1.4163%，因此 BLR 不进入 p6。MUMPS allocated 保守账下降不能替代实际 RSS 收益 Gate。

U3 第一次检查器错误地在 MUMPS 初始化前检查默认 ICNTL(38)，此时读回为 0；正式每次回代均读回 600。检查器改为核对实际回代的 36/37/38=0/0/600，仍严格核对 symbolic 前的 35=2 和 CNTL(7)=1e-5。首次检查结果保留，修复后只重新读取既有证据，没有重跑数值计算。最终决定为 `SELECT_EXACT`，进入 `v18_u4_original_exact.dat`。

U4 首次启动在完成凝聚和 H6 setup 后、创建 KSP 前因旧 `10800` 秒参数硬检查报错，PC 调用数为 0。失败源为 `4f15f7182289b3911bba6f766c5cd7e9a7026401`；全过程 monotonic 147.5273 s、峰值 RSS 2,504,851,456 B，swap 为零且完整清场。失败结果及实际费用永久保留。最小修复只让这一参数等值检查在 `enforce` 模式适用；正有限参数、原数值进展线和最大步数均保留。真实 PETSc KSP 补测覆盖 `observe_only` 的 43,200 秒观察参数和 50,000 秒观测值：仍能正常完成或按原 64 步数值线停止。相关测试 79 passed；随后只使用本批允许的一次 implementation-bug replay。


最终裁决：U4 唯一重放又在 PC 返回计时记录处异常，原始原因和清理覆盖错误均保留。停止后修复与99项测试通过，但未启动第三场PDE；U5条件不成立。完整逐项结果、费用、源SHA和边界见[response_v19](../response_v19.md)。
