# V19 双层单元凝聚：执行记录

本批依据 [Review V19](../review_report_v19.md)，起点为 `3c7b6ecfd7aede2651dd973052a097dbed601d03`，只运行新的 original。旧 notch 保持用户关闭，凝聚 BLR 关闭。

“单元凝聚”先在每个网格单元内部解出内部自由度与表面自由度的关系，再只对相邻单元共享的独立表面自由度和原 80 个端口迭代。完整场在需要时准确恢复。p6 原来已是 matrix-free；本批不删除一张原本存在的全局矩阵，而是改变外层向量长度并增加局部 LU、恢复和 Schur 缓存。

新逆桥严格使用 `J M_aug J^H`：把保留空间右端注入完整独立坐标，按原端口块构造输入，执行一次已有 BAL_H，再取完整纠正的独立 trace 和端口返回。一次非零 PC 仍含两次 V18 准确 p4 凝聚回代，不假定 `S4 = Pt^H S6 Pt`，不加入其他 PC、内层 KSP 或 BLR。

最终成功须独立重算恢复后原 `A6` 相对残差不超过 `1e-6`，端口操作尺度闭合不超过 `1e-8`，恢复与原算子恒等式误差不超过 `1e-10`，并通过原场、完整 80 模式、功率与资源 Gate。每 8 步保存两种真实残差，每 32 步先保存保留解，再做完整场评价。
